# 런타임 의존성 — 측정 계층(src/measurement/)과 의사결정 계층(src/decision/)이 실제로 import 하는 것만 적는다.
#
# ── 지원 Python 판 (#207 · docs/decisions/DR-207-python-runtime.md) ─────────────
# Supported runtime: Python 3.12
# Measurement-layer floor: Python 3.10
#
#   전체 파이프라인(이 파일 전체를 설치하는 실행)은 **3.12** 다. 아래 고정 버전의 Requires-Python:
#     numpy==2.5.4 · scipy==1.18.1 · shap==0.54.1  → >=3.12
#     pandas==3.0.6 · scikit-learn==1.9.1          → >=3.11
#     pyarrow==25.0.1 · PyYAML==6.0.3              → >=3.10 · >=3.8
#   그래서 3.10·3.11 에서 `pip install -r requirements.txt` 는 **설치 단계에서 실패한다.**
#   PRD NFR-04 `Python >= 3.10` 은 3.12 로 충족한다(3.12 ≥ 3.10).
#   측정 계층과 의존성 없는 테스트 스위트는 3.10 에서도 돈다 — python-compat.yml 이 매 PR 확인한다.
#   두 줄은 tests/test_runtime_declaration.py 가 Dockerfile · CI · 설치된 메타데이터와 대조한다.
#
# Resolved on Python 3.12.4 (CI parity — .github/workflows/isolation.yml pins 3.12).
# Local dev Python is 3.14.6; versions were NOT resolved there on purpose, because a
# release that only ships cp314 wheels would break CI. See .agent-team/08-impl-notes/backend.md.
#
# Exact pins (`==`), not ranges. Reason is NFR-001 reproducibility: a different pyarrow
# release can emit different Parquet bytes for identical input, which would make the
# SHA-256 comparison of events.parquet meaningless rather than merely noisy.
#
# ── Dependency containment (charter assumption A7) ─────────────────────────────
# .github/workflows/isolation.yml has NO install step, so every test must pass with
# none of these present. That holds because each dependency is confined to one module:
#   pyarrow -> src/measurement/sink.py       (lazy, function-local, guarded)
#   PyYAML  -> src/measurement/config_loader.py  (the only `import yaml` in src/measurement/;
#              scripts/gate1_judge.py imports it inside a function and exits 3 when absent)
# tests/test_neutrality.py enforces both containments as source checks.
# The ML stack below is confined to src/decision/ (never src/measurement/ — test_neutrality
# whitelists stdlib-only top-level imports there). Tests that need it skip with
# "BLOCKED: numpy/pandas/scikit-learn 미설치" in the no-install job; a skip is not a pass.

# Parquet writer/reader for the Event Sink. Optional at runtime: sink.py falls back to
# gzip JSONL via resolve_format("auto") when pyarrow is absent, and records which format
# it used in manifest.format so a digest is never compared across formats.
pyarrow==25.0.1

# YAML reader for config/economic_config.yaml and config/gate1_lock.yaml.
# Loaded with yaml.safe_load() ONLY. yaml.load(), FullLoader and unsafe_load are banned:
# CVE-2020-14343 (PyYAML < 5.4, patched 5.4) is reachable through FullLoader, and
# CVE-2026-24009 is the docling-core advisory that re-exposed it downstream. 6.0.3 is
# above every published PyYAML advisory range, but the loader choice is the actual
# control, so tests/test_neutrality.py asserts the unsafe loaders never appear.
PyYAML==6.0.3

# ── Decision layer (src/decision/, issue #144 sprint 1) ───────────────────────
# Versions are what the sprint venv (Python 3.12) actually ran — NOT re-resolved on a
# separate 3.12.4 environment like the two pins above. Exact pins for the same NFR-001
# reason: a different sklearn/numpy release can change tree splits and CV scores for the
# same seed, which would make model-report numbers non-reproducible.

# Array math for features, metrics and the F1 threshold search.
numpy==2.5.4
# Event frame (src/decision/data.py) and the vectorised feature table
# (src/decision/features/sprint_table.py). pandas reads Parquet through pyarrow (above).
pandas==3.0.6
# Churn baselines/proposed models (LogisticRegression · RandomForest · HistGradientBoosting),
# StratifiedKFold, imputation and metrics (src/decision/churn.py · clv.py).
scikit-learn==1.9.1
# Spearman rank correlation for CLV evaluation (src/decision/clv.py). Also an sklearn dependency.
scipy==1.18.1
# TreeExplainer feature attribution for the churn report. Failure is tolerated:
# churn.churn_importance() falls back to permutation importance and records that it did.
shap==0.54.1

# ── Deliberately absent ───────────────────────────────────────────────────────

#                                   requirements-ml.txt; no CI job installs it.
# lint · type checkers           -> this repo defines no lint/build/type gate (charter
#                                   §6.3). We do not invent a gate we cannot enforce.
