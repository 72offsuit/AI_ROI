# 런타임 의존성 — 측정 계층(src/measurement/)이 실제로 import 하는 것만 적는다.
#
# Resolved on Python 3.12.4 (CI parity — .github/workflows/isolation.yml pins 3.12).
# Local dev Python is 3.14.6; versions were NOT resolved there on purpose, because a
# release that only ships cp314 wheels would break CI. See .agent-team/08-impl-notes/backend.md.
#
# Exact pins (`==`), not ranges. Reason is NFR-001 reproducibility: a different pyarrow
# release can emit different Parquet bytes for identical input, which would make the
# SHA-256 comparison of events.parquet meaningless rather than merely noisy.
#
# ── Dependency containment (charter assumption A7) ─────────────────────────────
# .github/workflows/isolation.yml has NO install step, so every test must pass with
# none of these present. That holds because each dependency is confined to one module:
#   pyarrow -> src/measurement/sink.py       (lazy, function-local, guarded)
#   PyYAML  -> src/measurement/config_loader.py  (the only `import yaml` in the repo)
# tests/test_neutrality.py enforces both containments as source checks.

# Parquet writer/reader for the Event Sink. Optional at runtime: sink.py falls back to
# gzip JSONL via resolve_format("auto") when pyarrow is absent, and records which format
# it used in manifest.format so a digest is never compared across formats.
pyarrow==25.0.1

# YAML reader for config/economic_config.yaml and config/gate1_lock.yaml.
# Loaded with yaml.safe_load() ONLY. yaml.load(), FullLoader and unsafe_load are banned:
# CVE-2020-14343 (PyYAML < 5.4, patched 5.4) is reachable through FullLoader, and
# CVE-2026-24009 is the docling-core advisory that re-exposed it downstream. 6.0.3 is
# above every published PyYAML advisory range, but the loader choice is the actual
# control, so tests/test_neutrality.py asserts the unsafe loaders never appear.
PyYAML==6.0.3

# ── Deliberately absent ───────────────────────────────────────────────────────

# lint · type checkers           -> this repo defines no lint/build/type gate (charter
#                                   §6.3). We do not invent a gate we cannot enforce.
