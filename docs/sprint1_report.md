## 3. 모델 평가 — Baseline vs 제안

### 3.1 평가 설계
- **탐색 RCT**: t1(Day 273)에 최근 90일 활동 고객을 T0 50% · T1~T4 각 12.5% 무작위 배정 → 42일 관찰 → 학습 데이터
- **전략 비교**: t2(Day 315) 스냅샷에서 S0~S5 를 **같은 시점·같은 난수**로 복원해 각각 42일 진행 → 결과 비교
- Rule Baseline(S1)은 **AI 결과를 보기 전에 커밋**(`ce05a66`) — GATE 2 정신

### 3.2 Churn (T0 군 9,424명 · 42일 무구매 30.5%) — Stratified 5-Fold 평균 (± 표준편차)

| 모델 | 구분 | ROC-AUC | PR-AUC | F1 | Lift@10% |
|---|---|---|---|---|---|
| Rule(최근 구매 경과일) | Baseline | 0.819 ± 0.007 | 0.691 | 0.659 | 2.71 |
| Logistic Regression | Baseline | 0.895 ± 0.003 | 0.788 | 0.726 | 2.90 |
| Random Forest | 제안 | **0.897 ± 0.005** | 0.787 | 0.728 | 2.92 |
| HistGradientBoosting | 제안 | 0.893 ± 0.004 | 0.782 | 0.719 | 2.91 |

- 시간 홀드아웃(t1 모델 → t2 고객): RF ROC-AUC **0.901** · PR-AUC 0.814
- 해석: ML 은 Rule 보다 ROC-AUC **+0.078**. 제안 모델(RF·HGB)과 LogReg 의 차이는 fold 편차 안 — **"트리 모델이 낫다"고 말할 수 없다**
- 주요 Feature(SHAP): 관측 구매 빈도 · 관측 매출 · 90일 빈도 · 60일 결제 시작 수 · 90일 매출 · 구매 간격 CV

### 3.3 Uplift (RCT 18,848명)

| 처치 | ATE (42일 구매 유지) | 95% CI | Holm p |

| T1 무료배송 | +4.00%p | [1.99, 6.01] | 0.0003 |

SRM χ² p=1.0(배정 정상) · 검정력 T2 0.73, 나머지 ≥0.97.

| 전략 | 대상 | 처치 구성 | 매출 | 마케팅비(계획) | 이탈률 | 매출 증분 vs S1 |

## 5. 종합 점검

**성과**
- 계획 재편 당일 **전 구간(생성 → 예측 → 처치 → 비교 → ROI)이 한 명령으로 20K 규모에서 돈다** (25/25 단계)
- 생성 데이터의 근거를 모수 수준(출처 52건)과 실현 수준(stylized fact 17개 중 통과 11 · 경계 1 · 실패 5)으로 이중 증빙
- Churn ML 이 Rule 대비 ROC-AUC +0.078 · Uplift T-learner Qini 가 S-learner 의 1.9배 · AI 전략이 Rule 대비 이탈률 −2.1%p

**핵심 위험**
1. **모집단 정의 불일치**(#164) — 가드레일 판정이 정의에 따라 뒤집힌다
2. **처치 반응 이질성 부족**(#165) — Sleeping Dog 1.8% 로 Uplift 의 차별 가치가 작게 나올 수 있다
3. **증분이익 과대평가 가능성**(#169) — COGS 미차감 대체 계산
4. **미봉인 결과**(#163 · #171) — 정식 봉인 전에는 "AI 성능을 본 뒤 시뮬레이터를 고치는 누수"를 절차로만 막고 있다. 발표로 시뮬레이터 팀도 결과를 보게 되므로, 이후 보정은 외부 근거 · 사전 고정 기준만 근거로 하고 DR 에 남긴다
5. 실데이터가 아니라는 근본 한계 — 외부 타당성은 근거 대조와 공개 데이터 외부 검증(X5·Hillstrom)으로 보완
