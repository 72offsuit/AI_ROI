# 한계 (Limitations) — 스프린트 v0

| | |
|---|---|
| 범위 | 스프린트 v0(`sprint-v0`) 결과 — 실행 루프(#154) · 의사결정 계층(#156) · 시뮬레이터 S4~S6(#160) · 분석/모니터링(D11·D12) |
| 상태 | **미봉인.** 모든 결과 JSON 은 `"sealed": false` 다. GATE 1 은 부분 봉인(`PARTIAL_FREEZE`), GATE 2 는 정식 봉인 전이다 |
| 작성 원칙 | 수치는 출처(PR 본문 · `docs/research/data_grounding.md`)에 있는 것만 옮긴다. 여기서 새로 재거나 추정한 수치는 없다 |
| 작성 쪽 | 시스템 팀. 시뮬레이터 내부 · 숨김 영역 · ground truth 는 읽지 않았다 — 그래서 **정답 대비 성능이나 잠재결과 기반 수치는 이 문서에 없다** |

결과를 읽기 전에 아래를 먼저 본다. 이 목록에 있는 항목은 "결과가 틀렸다"는 뜻이 아니라 **결과를 어디까지 믿을 수 있는지의 경계**다.

---

## 1. 외부 타당성 — 시뮬레이터 위의 결과다

- 모든 학습 · 평가 · 전략 비교는 **시뮬레이터가 생성한 행동 로그** 위에서 이뤄졌다. 실제 서비스 고객에게 처치를 집행한 결과가 아니다. 성능 · 증분이익 · ROI 는 "생성 모형이 현실과 닮은 만큼만" 현실로 옮겨진다.
- 생성 모수의 외부 근거는 고르지 않다. 대조 35개 항목 중 정량 근거가 있는 것은 23개(정합 16 · 조정 권고 7), 방향 근거만 있는 것 5개, 근거가 없는 것 7개다(`docs/research/data_grounding.md` §1-5). 근거 없음에는 페르소나 구성비와 가격 · 쿠폰 · 피로 · 리뷰 성향 분포가 들어간다.
- 그래서 "유의미성"은 모수가 아니라 **실현 로그가 외부 stylized fact 17개(F1~F17)를 재현하는지**로 보기로 했다(같은 문서 §4). 이 판정의 최신 결과는 `docs/research/realism_report.json` 이 있을 때만 결과 폴더에 실린다 — 없으면 `run_meta.realism_report` 가 `not_run` 이다(#154).
- Sleeping Dog 비율 가드레일(8~15%)은 실데이터로 확인된 값이 아니라 **문헌 기반 가정**이다. 공개 실험 원자료를 세그먼트로 직접 집계했을 때 95% CI 상한이 0 미만인 음수 세그먼트는 0개였다(`data_grounding.md` §1-3).
- 시뮬레이터 쪽이 스스로 적은 한계 중 결과 해석에 걸리는 것: 행동 계수에 외부 출처가 없다는 점, 가드레일 실측이 seed 1~2개 · T0 1~2곳에 한정된다는 점, 이탈률 모집단 정의(직전 42일 구매 고객 vs eligible)가 아직 결정되지 않았다는 점(#160 "한계·미실행"). 이탈률 수치는 **모집단 정의를 함께 적지 않으면 비교하지 않는다.**
- 일부 이벤트 종류(`search` · `return_visit` · `review` · `cs_contact`)는 이 판의 시뮬레이터가 아직 생성하지 않는다(#160). 이 이벤트에 기대는 Feature 는 값이 아니라 결손이다. ANA-005(이탈 직전 CS 문의 빈도)는 이 판에서 의미 있게 계산할 수 없다.

## 2. 봉인 · 기준선

- **미봉인이다.** 결과는 GATE 1·2 봉인 이전 스프린트 실행이므로 "최종 비교"가 아니다. 봉인 후 `simulator/` 가 바뀌면 Baseline 부터 전 전략을 재실행한다(SRS FREEZE-003).
- **S1(Rule-based) 기준선은 AI 결과 이전에 커밋했지만 정식 GATE 2 봉인은 하지 않았다** — `ce05a66`. 정식 봉인 시 파일 경로(`strategies.py` vs `strategies/rule_based.py`) 합의가 필요하다(#156).
- **예산 기본값은 Lock 된 C_rule 이 아니다.** S1 을 상한 없이 실행한 비용을 S2~S5 예산으로 쓰고, 출처 우선순위와 실제로 쓴 출처를 `strategy_comparison.budget.source` 에 남긴다(#154 · DR-145). GATE 2 에서 C_rule 이 Lock 되면 바꿔야 한다.

## 3. 지표 정의의 근사

- **CLV 는 42일 매출이다.** 12개월 CLV 가 아니다(#154). 이익으로 환산할 근거(마진율)가 측정 계층에 없으면 S4 · S5 의 가치는 매출 기준이고 `run_meta.margin_rate` 에 그렇게 적는다.
- **증분이익 대체 계산.** 측정 계층의 기여이익이 기준선이나 전략 한쪽에라도 없으면 `Δ(매출 − 마케팅비)` 를 쓰고 `PROFIT_FALLBACK_REVENUE_BASED` 플래그를 붙인다. 이 값은 **COGS 를 빼지 않아 기여이익 증분을 과대평가**하고, 순매출(할인 후, DR-101)에서 쿠폰비를 다시 빼므로 쿠폰 할인을 이중 차감한다 — 기여이익의 대용이 아니라 방향 확인용이다(`src/decision/roi.py` · #156).
- **계획 비용과 실현 비용.** 마케팅비가 측정값이 아니라 계획치(`planned_treatment_cost_krw`)면 `MARKETING_COST_PLANNED_NOT_REALIZED` 가 붙는다. 계획 비용은 쿠폰 전량 사용 상한이라 같은 예산에서 AI 전략이 고르는 고객 수가 보수적으로 적다(#156).
- **증분 ROI** 는 기준선 대비 추가 마케팅비가 0 이하이면 계산 불가(`null`)다 — 비율이 음수 · 무한대가 되어 해석이 뒤집힌다(`roi.py`).
- AI ROI(PRD §64)는 AI 투자비가 주어질 때만 계산한다. 스프린트 실행은 투자비를 넘기지 않으므로 계산 불가다.

## 4. 모델 · 최적화

- S5 예산 최적화는 다중선택 배낭의 **탐욕 근사**다. 소규모 문제에서 전수 탐색 최적의 70% 이상만 테스트로 확인했고 LP 상계와는 비교하지 않았다(#156).
- X-learner 성향점수는 무작위 배정을 전제한 표본 비율 상수다(#156). 탐색 RCT 밖의 관측 데이터에는 그대로 쓸 수 없다.
- 세그먼트의 '≈0 띠'는 |uplift| 60% 분위수라 비-중립 고객 비율이 구조적으로 제한된다(#156).
- 신뢰구간(Bootstrap) · Final Holdout · 다중 T0(rolling)는 스프린트 범위 밖이다(#154). temporal holdout 은 t1 모델을 Feature(t2) 와 S0 분기의 42일 churn 으로 평가한 1회다.

## 5. 분석 · 모니터링 (D11 · D12, 이 문서와 같은 PR)

- **코호트는 가입월이 아니라 첫 구매월**이다. 관측 이벤트 16종에 가입 이벤트가 없다(SRS ANA-001 과 다름). 관측 첫 달 코호트에는 관측 이전 고객이 섞이므로 `left_censored_cohort` 로 표시한다. 관측이 끝나지 않은 경과 기간은 0 이 아니라 `null` 이다 — 스프린트 실행 기간이 짧아 M6 · M12 는 대부분 `null` 이다.
- **퍼널은 세션 구매 퍼널**(방문 → 상품조회 → 장바구니 → 결제시작 → 구매)이고 순서 퍼널이다. ANA-006 의 가입 → 첫 구매 → 재구매 → 충성 → 이탈 여정 퍼널은 가입 이벤트와 이탈 라벨 정의가 필요해 계산하지 않았다.
- **PSI 등급 기준(0.1 · 0.25)과 성능 하락 경보 기준(AUC −0.05 · Brier +0.02)은 업계 관행 값이며 근거 문헌이 없다** — 스프린트 가정이다. 비율 0 인 구간의 바닥값(1e-4)은 PSI 를 키우는 쪽이다.
- t1 · t2 Feature 드리프트는 **탐색 RCT 처치가 t1~t2 사이에 들어간 모집단**을 비교한다. 드리프트의 일부는 처치 효과 자체다 — "데이터가 변했다"와 "처치가 행동을 바꿨다"를 이 판에서는 가르지 않는다.
- 성능 추이(MON-002)는 함수만 있고 CLI 는 `not_run` 이다. 시점별 (y, p) 를 실행 루프가 넘겨야 채워진다.

## 6. 검증 범위

- 의존성(numpy · pandas · scikit-learn) 테스트는 의존성 없는 CI 잡에서 `BLOCKED: … 미설치` 로 skip 된다. **CI 의 skip 은 통과가 아니다**(#154 · #156).
- Python 3.10 실행은 로컬에서 하지 못했고 `python-compat` CI 잡에 맡긴다(#156 · #160).
