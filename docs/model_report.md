# 모델 보고서

## #218 Churn DL — 합성 준비 구현, 실제 비교는 미실행

2026-11-13 기준, 토큰 LSTM·CPU 학습·Early Stopping·최선 가중치 복원·`.pt` 저장/로드·
Validation 전용 앙상블 선택을 독립 모듈로 구현했다. 기존 일별 GRU·ML·오케스트레이션·
공통 config는 바꾸지 않았다. [설계 기록](decisions/DR-218-lstm-comparison.md)과
[합성 모델 카드](decisions/MC-218-lstm-synthetic.md)를 함께 본다.

현재 비교 결과는 공개 계약 형식 합성 fixture의 연결 검증이며, 실제 시뮬레이터 고객의 성능이 아니다.
64/24/24명 합성 예제에서 `.pt`·학습 로그·손실 곡선 CSV와 같은 시험 고객의 비교 JSON을 생성했다.
이 결과로 ML·DL 우열, 운영 모델 채택, 기여이익 개선을 주장하지 않는다.

최종 ML/DL/앙상블 비교에는 #215의 고객·시간 분할표, 라벨 창·적격성·출처·버전,
#214 저장 계약 인수와 실제 GATE 2 완료 확인이 필요하다. 현재 API는 합성/개발 검증용이며
정식 평가 또는 Final Holdout 호출을 받지 않는다. 공통 Test는 각 모델이 seed로 새로 만드는 대신
같은 고객 표·ID 해시·행 순서 해시로 대조한다. persona 접근 금지와 층화 요구의 충돌을 임의로 해소하지 않는다.

남은 일은 실제 입력 어댑터·시간 순서/5-Fold 연결·ML 예측 인수·오케스트레이션/영속화 통합,
학습 곡선 시각화·보정·신뢰구간·실패 고객군 보고와 독립 검수·리뷰다.
최종 모델 선택 근거와 실제 성능 표는 이 단계가 끝난 뒤 추가한다. Final Holdout은 사용하지 않았다.

### 독립 검수 반영

검수에서 확인한 결함을 #283~#288로 먼저 기록하고, 관측/출처의 내부 대조·고객 목록 고정·
Validation 선택 증거의 재계산·1e-12 수치 동점·완성 후 원자적 게시를 보완했다.
쓰기·게시 실패 시 성공 결과를 남기지 않으며 Test 접근 예약과 완료 상태를 구분한다.
배열·중첩 메타데이터를 호출자의 변경과 분리하고 라벨/예측 지문을 고객 ID와 결합한다.
외부 근거·학습 계보의 인증이나 전역 Test 접근 차단을 구현한 것은 아니다.

수정 전 합성 산출과 최초 검수는 보존했다. 수정 후 같은 합성 입력의 학습·저장/복원·비교를
새 출력 위치에서 다시 확인했다. 단일 run_id 강제는 도입하지 않았으며 공개 parent/child
계보와의 인수 계약, MPS RNG 가설은 미결정·미확인으로 남긴다.
