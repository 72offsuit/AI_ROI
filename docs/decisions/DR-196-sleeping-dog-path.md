| 상태 | 제안 — 값(안 A, scale 70)은 **사용자 결정**(2026-10-29), 리뷰 성환 |

## 무엇을 정하는가

1. 처치가 고객을 떠나게 만드는 경로(Sleeping Dog, D)를 어떻게 열고 그 크기를 무엇으로 두는가. 지금 판(sim-0.6)에서 정본 모집단(② §4.1 eligible) 기준 D 는 약 2% 로, 띠(8~15%)의 4분의 1이다.
2. 쿠폰 받기 배율(`coupon_click_scale_pct`)을 폐기된 25~40% 띠가 아니라 5~20% 띠 기준으로 다시 정한다.

손대지 않는 것(이슈 범위): Persuadable 띠와 Positive 쪽 반응 계수(`positive_scale_pct` · arms 민감도).

## 정하지 않으면 무엇이 막히나

- GATE 1(스프린트 3, #208)이 4분면 가드레일을 판정할 수 없다. 처치 지표를 ② 로 판정하게 된 뒤(DR-194) ATE 는 10~13%p 로 띠(3~6%p) 위다. P − D = ATE 라 D 가 2% 에 머물면 ATE 를 띠로 내릴 길이 Persuadable 을 깎는 것뿐이다 — 그건 이슈가 막았다.
- S8 채점(#224)의 4분면 정답에 Sleeping Dog 가 거의 없으면 "건드리면 안 되는 고객"을 구분하는 채점이 무의미해진다.

## 선택지

경로 자체는 하나로 정했다: **Negative 고객은 노출 순간 확률 `onset_at_exposure_pct` 로 이탈 진행(onset)에 들어간다**(DR-143 이 "이번 판에서 열지 않았다"고 남긴 길). 기존 Negative 효과(방문 −30% · 의향 −30% · onset hazard ×2)는 그대로 둔다. 남는 선택은 크기다.

| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| 0 | 경로만 연다(확률 100%), Negative 비율 그대로(배율 40) | 비율 계수를 안 바꾼다 | D 상한이 약 4.5%(Negative 고객이 ② 의 11% 뿐) — 띠의 절반 |
| **A** | 확률 100% + Negative 배율 40 → **70** | 세 띠(SD · P · ATE)에 가장 가까운 균형점 | SD 가 하한 아래(13K 기준 평균 7.3%) |
| B | 확률 100% + 배율 80 | SD 평균이 8% 를 넘는다 | ATE T2 · T4 가 3%p 아래, Persuadable T2 · T4 가 11% 경계 |
| C | 확률 100% + 배율 70 + P5 피로 μ 0.55 → 0.80(data_grounding §3-3 권고 방향) | SD 9% 로 여유 | ATE T2 · T4 약 1.7%p 로 크게 미달, 생성 분포가 바뀐다 |

## 결정

| # | 결정 |
|---|---|
| U1 | `treatment.negative_effect.onset_at_exposure_pct` **100** — Negative 고객은 노출 순간 이탈 진행에 들어간다(`_day_start` 의 onset 과 같은 처리, 이미 이탈 진행 중이면 그대로). 추첨은 그날의 전용 스트림(`negative_onset`)이라 다른 난수 자리를 밀지 않는다. **문헌 가정 — 외부 정량 근거 없음** |
| U2 | `treatment.negative_scale_pct` 40 → **70**(사용자 결정 안 A). Negative 확률 = 피로 × 70%. **문헌 가정** |
| U3 | `treatment.repeat_exposure.negative_max_pct` 60 → **90**(= 70 + 20). 상한이 첫 노출 배율보다 낮으면 반복 노출이 Negative 를 오히려 줄이는 모순이 생긴다 |
| U4 | `coupon_click_scale_pct` **45 그대로**. 5~20% 띠 기준으로 ② 5개 seed 에서 T2 13.4~14.4% · T3 7.7~8.6% — 띠 가운데(12.5%) 근처다. 50(구 띠 기준)에서 45 로 내린 #183 의 값이 새 띠에서도 맞다는 실측이 이 결정이다 |
| U5 | 판 `sim-0.6 → sim-0.7`, 생성 config `sim-gen-v4 → v5`(`CONFIG_PINS`), 상태 형식은 그대로(`sim-state-v4`) |

**근거:** 경로는 DR-143 이 미뤄 둔 "Negative 고객에서 처치가 이탈을 직접 일으키는 경로"이고, #195 의 무작위 실험(푸시가 앱 삭제를 늘림)과 같은 방향이다. 크기는 세 띠에 가장 가까운 균형점을 사용자가 골랐다. SD 8% 하한을 맞추면 ATE T2 · T4 가 3%p 아래로 내려가는 구조라(P − D = ATE), 어느 쪽이든 한 띠는 경계에 걸린다 — 안 A 는 SD 를 실험 근거(5~6.5%)와 문헌 가정(8%) 사이에 둔다.

## 기각한 안과 기각 사유

| 안 | 왜 택하지 않았나 |
|---|---|
| 0 경로만 | D 상한 약 4.5% — Negative 고객 수가 모자라 확률로는 더 오르지 않는다 |
| B 배율 80 | SD 는 띠 안이지만 ATE T2 · T4 가 띠 밖으로 나간다. 사용자가 균형점(A)을 택했다 — 13K 실측(위 표)으로 다시 볼 수 있다 |
| C P5 μ 상향 병행 | ATE 가 크게 미달하고 생성 분포(Trait)를 바꾼다. P5 μ 만으로는 D 가 1%p 남짓밖에 오르지 않아(실측 1) §3-3 권고 손잡이로는 부족했다 |
| Persuadable 쪽 축소로 ATE 맞추기 | 이슈 범위 밖(손대지 않는다) |

## 이 결정이 틀렸다면 어떻게 드러나나

- 같은 config 에서 경로 확률을 0 으로 두고 Negative 를 없애면(배율 0) 확률 0 · 100 의 이벤트가 같아야 한다. 다르면 경로가 발화하지 않을 때도 다른 추첨을 밀고 있다 — `tests/test_simulator_sleeping_dog.py`.
- 13K 다섯 seed 에서 SD 범위가 6.6~8.1% 다. 판이 바뀐 뒤 이 범위가 크게 내려가면(예: 5% 아래) 경로가 다른 변경에 묻힌 것이다.
- 항등식이 0.00%p 가 아니면 4분면 계산 결함이다(가드레일 `identity_*`).

## 민감도

| 바뀌는 값 | 변화 | 무엇이 달라지나 |
|---|---|---|
| `negative_scale_pct` | 60 · 70 · 80 | SD 약 6.6 · 7.7 · 8.2%(4K) / 7.3 · 8.3%(13K, 70 · 80). ATE 는 반대로 약 1%p 씩 |
| `onset_at_exposure_pct` | 0 · 50 · 100(배율 40) | SD 약 2.0 · 3.1 · 4.5% |
| P5 피로 μ | 0.55 → 0.80 | ② 의 Negative 비율 +2~4%p, SD +0.5~1.2%p |
| 표본 | 4,000 → 13,000명 | 같은 안 A 에서 SD 평균 7.7 → 7.3%, ATE T2 · T4 3.3 → 4.1~4.2%p — 4K 의 seed 잡음이 컸다 |

## 남은 불확실성

- **SD 하한 미달(안 A, 평균 7.3%)은 알고 둔 결과다.** 하한 8% 의 근거는 모형 세그먼트 추정뿐이고(#195), 실험 근거는 5~6.5% 다. GATE 1 판정 기준(#208)에서 SD 하한을 그대로 둘지 리드가 정한다.
- **ATE T3 는 평균 7.7%p 로 띠 위다.** T3(강한 쿠폰)의 Positive 쪽 효과가 크다 — Positive 계수는 이 이슈 범위 밖이라 그대로 뒀다. 처치 효과 크기는 별도로 연다.
- **생성 이탈률 ① 이 5개 seed 모두 띠 아래(13.9~14.7%)다.** 이 경로는 처치군에만 작동해 T0(무처치) 팔의 이탈률을 바꾸지 않는다 — #183(sim-0.6)의 보정 값에서 온 것이다. #183 에 알린다.
- 결과 변수가 다르다: 외부 근거는 앱 삭제·이탈, 우리 SD 는 42일 안 구매 여부다. 자릿수만 참고했다.
- 실측은 small 프로필 · 180일차 한 시점이다. 다른 T0 와 rolling 프로필은 재지 않았다.
