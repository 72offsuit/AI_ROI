# DR-196-sleeping-dog-path — Sleeping Dog 직접 경로와 Negative 비율 · 쿠폰 받기 배율

| | |
|---|---|
| 태스크 | #196 (부모 #165 · 근거 #195 · 모집단 DR-194) |
| 작성 | 민정 · 2026-10-29, 2026-10-30 갱신(#183 재보정 위로 다시 잼) |
| 상태 | 제안 — 값(배율 100)은 **사용자 결정**(2026-10-30), 리뷰 성환 |

## 무엇을 정하는가

1. 처치가 고객을 떠나게 만드는 경로(Sleeping Dog, D)를 어떻게 열고 그 크기를 무엇으로 두는가. 경로가 없는 판(sim-0.6, #183 재보정)에서 정본 모집단(② §4.1 eligible) 기준 D 는 약 1~2% 로 띠(8~15%)에 한참 못 미친다.
2. 쿠폰 받기 배율(`coupon_click_scale_pct`)을 폐기된 25~40% 띠가 아니라 5~20% 띠 기준으로 다시 정한다.

손대지 않는 것(이슈 범위): Persuadable 띠와 Positive 쪽 반응 계수(`positive_scale_pct` · arms 민감도).

## 정하지 않으면 무엇이 막히나

- GATE 1(스프린트 3, #208)이 4분면 가드레일을 판정할 수 없다. 처치 지표를 ② 로 판정하게 된 뒤(DR-194) ATE 는 띠(3~6%p) 위다. P − D = ATE 라 D 가 작으면 ATE 를 띠로 내릴 길이 Persuadable 을 깎는 것뿐이다 — 그건 이슈가 막았다.
- S8 채점(#224)의 4분면 정답에 Sleeping Dog 가 거의 없으면 "건드리면 안 되는 고객"을 구분하는 채점이 무의미해진다.

## 선택지

경로 자체는 하나로 정했다: **Negative 고객은 노출 순간 확률 `onset_at_exposure_pct` 로 이탈 진행(onset)에 들어간다**(DR-143 이 "이번 판에서 열지 않았다"고 남긴 길). 기존 Negative 효과(방문 −30% · 의향 −30% · onset hazard ×2)는 그대로 둔다. 남는 선택은 Negative 고객 수(배율 `negative_scale_pct`, Negative 확률 = 피로 Trait × 배율)다.

| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| 0 | 경로만 연다(확률 100%), 배율 40 | 비율 계수를 안 바꾼다 | Negative 고객이 모자라 D 상한이 약 4.5%(옛 바탕 실측) |
| A | 확률 100% + 배율 70 | 옛 바탕(#183 첫 보정, onset 10,000)에서는 세 띠의 균형점이었다 | 새 바탕(onset 14,500)에서 SD 6.1% · ATE 7~11%p — 거의 모든 띠 밖 |
| **B** | 확률 100% + 배율 **100**(상한, Negative 확률 = 피로 Trait) | 새 바탕의 보정 · 확인 seed 모두에서 SD · P · ATE(T3 제외) · 쿠폰 · 이탈률이 띠 안 | 상한이라 더 올릴 여지가 없다. 반복 노출이 Negative 를 더 늘리지 못한다(아래) |
| C | 확률 100% + 배율 100 + P5 피로 μ 0.55 → 0.80(data_grounding §3-3 권고 방향) | SD 여유가 크다(약 10%) | ATE T2 · T4 가 1.5~1.7%p 로 크게 미달, 생성 분포(Trait)가 바뀐다 |

## 결정

| # | 결정 |
|---|---|
| U1 | `treatment.negative_effect.onset_at_exposure_pct` **100** — Negative 고객은 노출 순간 이탈 진행에 들어간다(`_day_start` 의 onset 과 같은 처리, 이미 이탈 진행 중이면 그대로). 추첨은 그날의 전용 스트림(`negative_onset`)이라 다른 난수 자리를 밀지 않는다. **문헌 가정 — 외부 정량 근거 없음** |
| U2 | `treatment.negative_scale_pct` 40 → **100**(사용자 결정 2026-10-30). Negative 확률 = 피로 Trait 그대로. **문헌 가정** |
| U3 | `treatment.repeat_exposure.negative_max_pct` 60 → **100**. 상한이 첫 노출 배율보다 낮으면 반복 노출이 Negative 를 줄이는 모순이 생긴다. **결과: 배율이 이미 상한이라 반복 노출(#183 ④)은 Positive 만 줄이고 Negative 를 더 늘리지 않는다** — 반복 노출 피로의 Negative 쪽은 이 판에서 꺼진 셈이다(테스트 `test_simulator_fatigue` 가 이 상태와, 배율 40 · 상한 60 에서의 증가 모양을 함께 고정한다) |
| U4 | `coupon_click_scale_pct` **40 그대로**(#183 재보정 값). ② 에서 T2 11.5~11.8% · T3 7.0~7.1% 로 5~20% 띠 안이다 |
| U5 | 판 `sim-0.6 → sim-0.7`, 생성 config `sim-gen-v4 → v5`(`CONFIG_PINS`), 상태 형식은 그대로(`sim-state-v4`). 판정 seed 는 보정 42~46 · 확인 47~51(#243 과 같다) |

**근거:** 경로는 DR-143 이 미뤄 둔 "Negative 고객에서 처치가 이탈을 직접 일으키는 경로"이고, #195 의 무작위 실험(푸시가 앱 삭제를 늘림)과 같은 방향이다. 크기는 보정 seed 에서 고르고 확인 seed 에서 같은 결론이 나는지 봤다. 배율 100 은 SD · P · ATE(T3 제외) · 쿠폰 · 이탈률을 두 seed 묶음 모두에서 평균 띠 안에 둔다.

## 기각한 안과 기각 사유

| 안 | 왜 택하지 않았나 |
|---|---|
| 0 경로만 | Negative 고객 수가 모자라 D 가 띠 아래에 머문다 |
| A 배율 70 | 새 바탕에서 SD 6.1% · ATE 7~11%p — 거의 모든 띠 밖 |
| C P5 μ 상향 병행 | ATE T2 · T4 가 크게 미달하고 생성 분포(Trait)를 바꾼다 |
| Persuadable 쪽 축소로 ATE 맞추기 | 이슈 범위 밖(손대지 않는다) |

## 이 결정이 틀렸다면 어떻게 드러나나

- 같은 config 에서 Negative 를 없애면(배율 0) 경로 확률 0 · 100 의 이벤트가 같아야 한다. 다르면 경로가 발화하지 않을 때도 다른 추첨을 밀고 있다 — `tests/test_simulator_sleeping_dog.py`.
- 판정 seed(42~51)의 SD 평균이 8% 아래로 내려가면 경로가 다른 변경에 묻힌 것이다. 배율은 이미 상한이라, 그때는 P5 피로 μ(안 C) 같은 다른 손잡이를 연다.
- 항등식이 0bp 가 아니면 4분면 계산 결함이다(가드레일 `identity_*`).

|---|---|---|

## 남은 불확실성

- **최근 구매 고객(① 직전 42일 구매)에게는 처치가 순손해다(#246 리뷰).** 판정 모집단이 아닌 참고 행(`active42_*`, DR-194 U3)에서, 13,000명 × seed 42~51 평균 ATE T1~T4 가 **−8.0 ~ −9.0%p**, Sleeping Dog **12.7 ~ 13.0%**, Persuadable 4.0 ~ 5.0% 다(경로 전 sim-0.6 은 ATE +3.0 ~ +4.3%p · SD 1.2 ~ 1.6% — 성환 재현 seed 42 · 47, 배율 70 에서도 −3.9 ~ −4.9%p). Negative 가 전체의 약 27.5%(`RESPONSE_MIX_GOLDEN` n=0: 1,376 / 5,000)이고 노출 즉시 이탈 진행에 들어가는데, ① 은 기저 구매율이 높아 Positive 가 더할 몫이 작고 Negative 가 잃는 몫이 크다. ① 은 판정 모집단이 아니고 RCT 도 ② 만 받지만, ② 안에 마지막 구매 14~42일 전 고객(① ∩ ②)이 섞여 있어 시스템 팀 모델이 배우는 이질성(최근 구매 고객 = Sleeping Dog)의 크기가 이 값으로 정해진다. 또 ATE 띠의 외부 근거 중 Hillstrom(+4.5 · +7.7%p)은 활성 고객 대상이라 같은 성격의 ① 에서 부호가 반대다. 이 크기를 받아들일지는 ATE 띠의 모집단(#208, 리드)과 함께 정한다 — 이 DR 에서 값을 바꾸지 않는다.
- **배율이 상한이다.** 다음에 D 를 더 올려야 하면 배율은 쓸 수 없고 P5 피로 μ(안 C)나 Negative 효과 크기를 연다. 반복 노출 피로의 Negative 쪽(#183 ④)은 이 판에서 작동하지 않는다(U3).
- **개별 seed 는 경계에 걸린다.** SD 최솟값 7.85%, ATE T2 · T4 최솟값 2.45~2.84%p — 평균은 띠 안이고 각 seed 는 경계(±20%) 안이다(#243 의 판정 기준과 같다).
- **ATE T3 는 평균 6.8~7.1%p 로 띠 위다.** T3(강한 쿠폰)의 Positive 쪽 효과가 크다 — 이 이슈 범위 밖이다.
- **ATE 띠의 모집단이 정해져 있지 않다**(DR-194 「남은 불확실성」) — 띠를 ② 에 대는 것이 맞는지에 따라 이 결정의 여유가 달라진다.
- 결과 변수가 다르다: 외부 근거는 앱 삭제 · 이탈, 우리 SD 는 42일 안 구매 여부다. 자릿수만 참고했다.
- 실측은 small 프로필 · 180일차 한 시점이다. 다른 T0 와 rolling 프로필은 재지 않았다.
