# DR-217-margin-cate — 기여이익률이 없으면 S4 · S5 를 돌리지 않고, 고객별 τ̂ 을 `cate.jsonl` 로 남긴다

## 무엇을 정하는가

1. 기여이익률(`margin_rate`)이 없을 때 S4 · S5 · What-if 의 기대 증분가치(CATE × CLV × margin_rate)를 어떻게 할 것인가.
2. S8 사후 진단이 받을 고객별 τ̂ 을 어떤 파일 · 어떤 기준 시각 · 어떤 고객으로 남길 것인가(DR-S8 결정 1).

## 정하지 않으면 무엇이 막히나

- 이익률 근거가 없는 실행에서 S4 · S5 가 42일 **매출** CLV 를 이익으로 취급한 값으로 대상을 고르고, 결과표에는 그 사실이 드러나지 않는다.
- S8 채점(#227)이 고객별 τ̂ 을 받지 못해 PEHE · corr(τ̂, τ) · Qini 달성률을 계산하지 못한다(세그먼트 평균만으로는 qini_oracle 만 partial).

## 선택지

| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| 이익률 A | 없으면 S4 · S5 · What-if 를 not_run | 매출을 이익으로 부르지 않는다. 사유가 결과에 남는다 | 이익률 근거가 없는 실행에서 두 전략이 비교에서 빠진다 |
| 이익률 B | 없으면 기본 1.0(현행) | 언제나 돈다 | 기대 증분가치가 이익률만큼 부풀고 조용하다 |
| 이익률 C | 없으면 외부 공시 매출총이익률(30~33%)로 | 언제나 돈다 | #203 조사 결론 — 공시 매출총이익률은 우리 기여이익률 정의와 같다는 근거가 없다 |

| τ̂ B | t2 만 | 파일이 작다 | S8 Qini(RCT 분기)를 낼 수 없다 |

## 결정

1. **이익률 = 안 A.** `strategies._value` 는 `margin_rate` 가 없으면 `NotComputable`, S4 · S5 의 필수 점수(`REQUIRED_SCORES`)에 `margin_rate` 를 넣었다. 실행 루프 What-if 도 없으면 not_run 과 이익률 근거의 사유. S2 · S3 은 가치를 쓰지 않아 영향이 없다. DR-145 의 해당 문장은 번복으로 표시했다.
2. **τ̂ = 안 A.** 결과 폴더에 `cate.jsonl` — 한 줄 = 한 고객 · 한 기준 시각, 열은 정확히 `customer_id · t0 · cate_T1 · cate_T2 · cate_T3 · cate_T4`(다른 키를 넣지 않는다). 계산할 수 없는 처치군은 null.
   - t1: RCT 배정 고객 중 Feature(t1) 이 있는 고객. t2: 점수를 매긴 고객(Feature(t2)).
   - 파일 밖 기록 `uplift_eval.cate_file` 에 행 수 · null 포함 행 수 · `in_sample_t1` · 계약 문장을 남긴다. **같은 실행에서 학습한 모델의 t1 τ̂ 은 학습 데이터 위 예측**이다 — S8 채점은 모델을 불러온 Final Holdout 실행(#226, `--load-models`)의 파일로 한다.
   - 쓰지 못해도 결과 파일 쓰기는 이어 가고 사유를 남긴다(not_run · failed).

## 기각한 안과 기각 사유

| 안 | 왜 택하지 않았나 |
|---|---|
| 이익률 B(기본 1.0 유지) | 매출을 이익으로 부르고 조용하다 — 이 프로젝트의 "계산 불가를 다른 값으로 메우지 않는다" 규율 위반 |
| 이익률 C(외부 공시율) | #203 이 기각 근거를 남겼다 — 정의 범위가 다르다 |
| τ̂ B(t2 만) | S8 Qini 를 낼 수 없다(DR-S8 M3 은 RCT 분기에서만 잰다) |
| `cate.jsonl` 에 `in_sample` 열 추가 | S8 이 받기로 한 형식이 아니다 — 시뮬 팀 채점기가 모르는 키를 받게 된다. 파일 밖 기록으로 둔다 |

## 이 결정이 틀렸다면 어떻게 드러나나

- 이익률 근거가 있는데도 S4 · S5 가 not_run 이다 → `margin_rate_basis` 의 판정이 틀린 것이다(`run_meta.margin_rate` 의 사유를 본다).
- S8 이 `cate.jsonl` 을 읽지 못하거나 t0 를 맞추지 못한다 → 기준 시각 표기(ISO 8601, KST 오프셋)가 분기 목록과 다른 것이다 — 성환의 연결 키 함수 PR(#226 전)의 시험으로 맞춘다.
