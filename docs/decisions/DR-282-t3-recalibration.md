## 무엇을 정하는가

GATE 1 필수 검사 중 `ate_T3`(② · T3 vs T0 · 42일 구매 ITT)가 DR-208 띠(3~6%p) 위에 있다. 판정 기준을 옮기지 않고 시뮬레이터의 T3 처치 반응 계수를 낮춰 띠 안으로 들인다. 무엇을 · 얼마나 낮출지와 그 선택 규칙을 정한다.

## 정하지 않으면 무엇이 막히나

- GATE 1 실측(11/19, 확인 seed 47~51): 지금 판(sim-0.8)이면 `ate_T3` 필수 검사가 불통과할 것으로 예상된다(DR-196 · DR-208 「이 결정이 틀렸다면」). 봉인 · 서명(#210 몫)이 막힌다.
- 시스템 팀 결과 재생성: 판이 바뀌므로 봉인 전에 한 번에 바꿔야 한다.

## 결정

**조정 대상 A · 목표 A.** 후보군과 선택 규칙은 탐색 **전에** 고정했다(사용자 결정 2026-11-13).

- 후보: T3 강도 = T1 + α × (T3 현재 − T1), α ∈ {1.0, 0.75, 0.5, 0.25, 0}. 네 계수를 같은 α 로 줄이고 Python `round` 로 정수화한다.
- 측정: 의존성 설치한 3.12, `python -m src.simulator guardrails --seed {42..46} --customers 13000 --profile small --warmup-days 180 --config {후보 config}`. **확인 seed 47~51 은 실행하지 않았다.**
- 선택 규칙: 보정 seed 42~46 에서 DR-208 필수 검사가 모두 통과(평균 띠 안 + 각 seed 경계 이내, 4분면 일관성 \|gap\| ≤ 50bp)하고, 평균 `ate_T3` 가 4.5~5%p 이며, 평균 `ate_T3` 가 T1 · T2 · T4 평균보다 큰 α 중 4.75%p 에 가장 가까운 것.

탐색 결과(sim-0.8 바탕 `9de2c44`, 보정 seed 42~46 평균, ②):

| α | T3 방문 · 의도 · 보호 · 회복 | 필수 검사 전부 | `ate_T3` | 4.5~5%p | T3 > 다른 팔 |
|---|---|---|---|---|---|
| 1.0 (sim-0.8) | 30 · 35 · 60 · 50,000 | ✗ | 7.05%p | ✗ | ✓ |
| 0.75 | 28 · 32 · 58 · 45,000 | ✗ | 6.37%p | ✗ | ✓ |
| 0.5 | 25 · 30 · 55 · 40,000 | ✓ | 5.58%p | ✗ | ✓ |
| **0.25** | **22 · 28 · 52 · 35,000** | **✓** | **4.52%p** | **✓** | **✓** |
| 0 | 20 · 25 · 50 · 30,000 | ✓ | 3.65%p | ✗ | ✗ |

α 0.25 의 다른 값(보정 seed 평균): 이탈률 ① 15.58% · 쿠폰 T2 11.84% · T3 6.40% · Sleeping Dog T3 8.79% · Persuadable T3 13.31% · 4분면 일관성 0bp · ATE T1 4.51 / T2 3.52 / T4 3.27%p. `ate_T3` seed 값 4.99 · 6.08 · 3.86 · 4.09 · 3.57%p.

**선택: α = 0.25 — T3 방문 22 · 구매 의도 28 · 이탈 보호 52 · 회복 35,000ppm.** 쿠폰(7,000원 · 50,000원 · 14일) · 다른 팔 · 전역 계수는 그대로. 판 `sim-0.8` → **`sim-0.9`**, `config_version` `sim-gen-v6` → **`sim-gen-v7`**.

**근거:** 규칙을 만족하는 후보가 α 0.25 하나다. 0.5 는 필수 검사를 통과하지만 목표 구간 밖이고, 0 은 T3 가 T1 보다 약해진다. 정수화가 half-even 이라 22.5 → 22 · 27.5 → 28 · 52.5 → 52 다 — 측정한 config 를 그대로 정본에 옮긴다.

## 기각한 안과 기각 사유

| 안 | 왜 택하지 않았나 |
|---|---|
| 조정 대상 B (쿠폰 금액 · 최소 주문) | 측정 계층 경제 규칙 · 봉인 가정 `A-DISCOUNT` 를 함께 바꿔야 한다 — 양 팀 합의 · 공유 경로 변경이라 봉인 일정 안에 안전하게 할 수 없다 |
| 조정 대상 C (전역 배율) | 하한 근처인 T2 · T4 가 띠 아래로 갈 것으로 추정된다(전역 배율은 탐색하지 않아 실측 근거는 없다) |
| 목표 B (상한 아래) | 보정 seed 에서도 α 0.5(5.58%p)의 한 seed 가 7.19%p 로 경계 근처다 — 확인 seed 에서 띠 밖 위험 |
| 목표 C (보고 고르기) | 선택 기준을 사전에 고정하지 못해 "결과를 보고 고쳤다"와 구분되지 않는다 |
| α 0.5 | 필수 검사는 통과하지만 목표 구간(4.5~5%p) 밖 — 규칙에서 제외 |
| α 0 | T3 가 T1 보다 약해진다(가장 큰 쿠폰 처치가 가장 약한 효과) |

## 이 결정이 틀렸다면 어떻게 드러나나

- 11/19 확인 seed 47~51 실측에서 `ate_T3` 가 띠 밖이거나 다른 필수 검사가 깨지면 이 보정은 확인 seed 에서 성립하지 않은 것이다. 그때 기준(DR-208)은 옮기지 않고 GATE 1 은 불통과다 — 봉인일을 #163 에서 다시 잡는다.
- 정본 config 로 보정 seed 를 다시 돌린 값이 위 표와 다르면 옮겨 적기가 틀린 것이다.

## 민감도

- α 를 0.25 단위로 바꾸면 `ate_T3` 보정 seed 평균이 표 전체에서 약 0.7~1.1%p, α 0.25 양옆 구간에서 약 0.9~1.1%p 움직인다(표). α 0.25 의 seed 범위(3.57~6.08%p)는 각 seed 허용 범위(2.4~7.2%p) 안이다.
- "T3 > 다른 팔"의 여유가 매우 작다(T1 평균보다 0.01%p 큼). 참고 조건이고 GATE 판정 대상은 아니다 — 확인 seed 에서 T3 ≤ T1 이 나와도 GATE 판정은 바뀌지 않는다. 발표 서술("T3 가 가장 강한 처치")은 그 결과를 보고 고친다.
- Persuadable T3 는 15.77 → 13.31% 로 내려가 하한(11%)과의 여유가 줄었다.
- 쿠폰 사용률 T3(필수 검사)도 7.11 → 6.40% 로 내려가 하한(5%)에 가까워졌다. 각 seed 는 6.11~6.51% 로 경계(4%) 안이다.

## 남은 불확실성

- 확인 seed 47~51 에서의 값은 모른다 — 11/19 실측에서 처음 잰다.
- T3 계수 값 자체의 외부 근거는 없다(가드레일 띠 보정값). 띠가 실제 리텐션 효과보다 크게 둔 가정이라는 한계(DR-208)는 그대로다.
- realism 기록 검사는 보정 seed 42~46 으로만 점검했다(`run_world` reference · 315일 · 배정 180일차 → `realism_check`, 판정 스크립트 #276 으로 seed 만 42~46 으로 바꾼 점검용 기준). F1~F11 · F13 은 5 seed 평균 모두 통과, **F17 은 값 없음(no_data)** 이다 — 1회 배정 세계에서 처치군 1인당 매출 증분이 0 이하라 "증분 중 쿠폰 미사용 몫"이 정의되지 않는다. 같은 seed 42 를 이번 변경 전 계수(sim-0.8 의 T3)로 돌려도 no_data 였다 — 이 재보정이 만든 상태가 아닐 가능성이 높지만 **seed 42 하나로만 확인했다**(43~46 의 변경 전 상태는 재지 않았다). DR-208 규칙상 11/19 실측에서도 no_data 면 봉인 PR 전에 원인을 DR 에 기록해야 한다.
- 정본 config 로 보정 seed 42~46 을 다시 돌린 가드레일 값은 탐색 때 α 0.25 값과 모든 검사에서 같았다(판 문자열만 sim-0.9).
