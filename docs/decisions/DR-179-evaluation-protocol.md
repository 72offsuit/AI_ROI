## 무엇을 정하는가

기존 고객 미래 성능의 모집단 감사, Test 위험도 기준선의 학습 범위, 동점 곡선과 Top-k 정의를 정한다. 최신 main 68759ebe와 #247의 Eligible(t1/t2) 적용을 보존한다.

## 정하지 않으면 무엇이 막히나

평가 고객의 라벨이 위험도 모델에 들어가거나 동점의 입력 순서가 Qini·Top-k를 바꿀 수 있다. 고객 교집합을 숨긴 미래 성능을 새 고객 일반화로 오해할 수 있다.

## 선택지

| 안 | 내용 | 적합성 |
|---|---|---|
| M | evaluate 정제 후 실제 Train의 T0 대조군만 학습 → 같은 Test에 ID로 예측 | Test 위험도 기준선에 한정해 리드 수용 |
| 전체 OOF | 모든 개발 고객의 교차적합 예측을 공유 | Validation·선택·Train 보고까지 확대할 때 재검토 |
| 전역 최종 Churn 모델 | 전체 T0에서 고른 모델 재사용 | 실제 Test의 학습·선택 참여 위험으로 기각 |
| 동점 끝점 | 서로 다른 점수 묶음의 끝점으로 곡선·면적 정의 | 리드 수용, 지표 버전 변경 필요 |
| 행 순서·ID로 동점 해소 | 같은 점수에 추가 순위 부여 | 점수에 없는 정보를 넣어 기각 |

## 조사한 것

[리드 결정](https://github.com/72offsuit/AI_ROI/issues/179#issuecomment-6494889527)과 [검수 반영 의견](https://github.com/72offsuit/AI_ROI/issues/179#issuecomment-6499361457)을 정본으로 삼는다. v03 합성 조사에서 전역 모델의 위험도 성능 부풀림, 결측 제거 전 분할의 Test 중복, 동점 순열 의존성을 재현했다. 프로젝트 실제 성능을 뜻하지 않는다. 기존 모델·전처리 사양은 config/model_config.yaml과 churn.make_model을 재사용한다.

## 결정

R2는 실제 학습·선택 입력과 미래 평가 입력의 고객 수·정렬 ID 해시·교집합·처치 구성·결손 전후를 감사한다. 보고 범위는 기존 고객의 미래 시점 성능이다. 감사만으로 SPLIT 충족을 선언하지 않는다. C 임시 분할은 만들지 않고 정식 고객 60/20/20+시간 분할 D는 #179 밖이다.

R3는 M을 적용한다. 위험도 모델은 사전 고정한 logistic_regression으로 시작하며 churn.risk_baseline_model에 적는다. 기존 C=0.5·max_iter=2000·balanced와 Train-fit 전처리를 그대로 쓴다. 이는 안전한 비교 기준의 고정이며 성능 우월성 판단이 아니다. RF·HistGB 비교는 기존 make_model·config의 알고리즘과 사양을 정적으로 대조한 것이며, 데이터로 후보를 학습·평가해 고르는 탐색은 0회다. 실제 정제 후 Train∩T0만 fit하고 retention의 반대인 churn을 학습한다. Test 라벨은 fit·전처리·사양 선택에 넘기지 않는다. 한 클래스·ID/점수/입력 충돌·학습 실패는 위험도 행만 not_run으로 격리한다.

2026-10-30 N1 검토와 사용자의 방어 보완 지시에 따라 외부 churn_p 경로는 비활성화한다. attrs에 고객 ID·사양·프로토콜을 적어도 학습 사실을 검증할 수 없기 때문이다. 해당 인자는 즉시 전체 평가 예외를 내는 대신 위험도 행만 not_run으로 남기는 호환 진입점으로 보존한다. 정상 S/T/X 평가는 유지한다. factory와 외부 점수 동시 입력도 factory를 실행하지 않고 위험도 행만 거부한다. 내부 경로의 lineage_verification=fit_observed_in_evaluator는 현재 evaluator에서 fit을 관찰했다는 뜻이며 외부 선언을 인증했다는 뜻이 아니다.

R4 지표 버전은 tied-endpoints-v1, Top-k는 fractional-boundary-v1이다. 곡선과 면적은 같은 동점 묶음 끝점으로 계산하고 면적 계산 후 표시 점을 줄인다. 기존 무동점 계산·축·정규화는 유지한다. Top-k는 기존 round(N×fraction), 최소 1명이라는 명목 인원을 유지하고 경계 동점 묶음에 남은 인원/묶음 크기의 가중치를 준다. 양 군 분자·분모에 모두 적용하며 어느 군의 가중 분모가 0이면 null이다. 이는 비례 가중 규약이며 무작위 동점 추출의 평균 비율과 같다고 주장하지 않는다. 실제 호출의 S-learner 점수 동점 비율을 함께 산출한다.

## 기각한 안과 기각 사유

Train 내부에서 위험도 사양 선택도 하지 않는다. 원문 OOF 전체를 보편 기각하지 않으며 M의 적용 범위가 확대되면 다시 검토한다. Test 점수로 최종 후보를 고르지 않는다. Top-k 동점 전원 포함은 예산·도달률을 바꾸므로 채택하지 않는다. 미세 잡음·ID 2차 정렬도 채택하지 않는다.

## 이 결정이 틀렸다면 어떻게 드러나나

factory의 fit 고객이 실제 Test와 겹치거나 Test 라벨만 바꿨는데 fit 입력·사양·위험도 예측이 바뀐다. 위험도 오류가 정상 S/T/X를 멈춘다. 동점 행 순열에 따라 곡선·면적·Top-k가 달라진다. 표시 곡선과 면적의 정의가 다르거나 실제 동점률 대신 합성 결과를 프로젝트 결과로 게시한다.

## 민감도

결측 마스크·처치·seed를 고정한 Test 라벨 변경, 학습 T0 한 클래스·빈 표본, 중복·누락 ID, NaN/Inf·범위 밖 확률, 동점 없음·일부·전부, 경계 동점의 양 군 가중 분모, 곡선 표시 점 수를 시험한다.

## 남은 불확실성

실제 개발 데이터의 S-learner 동점률·정상 위험도 성능은 재실행 전 미확인이다. 합성 학습은 연결·반례 검증용이다. Final Holdout은 사용하지 않는다. 실제 시뮬레이터 통합·독립 검토·PR·병합은 별도 완료 조건이다.
