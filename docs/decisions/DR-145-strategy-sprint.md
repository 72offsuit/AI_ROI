## 무엇을 정하는가

1. S1 Rule-based 기준선의 선정 규칙(N 일, 처치, 순서, 예산 처리).
2. S2~S5 가 무엇으로 고객을 고르고 어떤 처치를 주는가.
3. S5 예산 최적화를 어떤 근사로 풀고, 그 근사가 무엇을 보장하지 않는가.

## 정하지 않으면 무엇이 막히나

Incremental Profit(PRD §63)은 S1 대비 차이로만 정의된다. S1 이 정해지지 않으면 S2~S5 의
어떤 수치도 해석할 수 없고, AI 결과를 본 뒤 S1 을 정하면 BASE-003 위반이다. 오케스트레이션
(D9)·대시보드 전략 비교표(STR-003)가 `plan()` 시그니처에 묶여 있다.

## 선택지

| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| A | S1 = 28~90일 미구매 · 구매 2회 이상 → T3, recency 내림차순 (data_spec §12.1 원안) | 기존 설계 문서와 같다. 고위험 고객을 정확히 겨냥하는 '정직한 상대' | 상한 90일·구매 2회 조건은 문헌 근거가 아니라 실무 관례 |
| B | S1 = 30일 미구매 → T3 (과제 예시 "30일 미구매") | 단순 | 프로젝트 At Risk 정의(28일)와 어긋나고, 1회 구매 고객까지 포함 |
| C | S1 = 42일(Churn 정의) 이상 미구매 → T3 | 이미 이탈한 고객만 노린다 | Win-back 이 아니라 사후 복구가 되어 기준선이 약해진다(Incremental Profit 과대) |

## 조사한 것

| 출처 | 무엇을 말하나 | 우리 맥락에 얼마나 맞나 |
|---|---|---|
| PRD §28 · SRS churn 규칙 | At Risk = 28일 미구매, Churn = 42일 이상 미구매 (프로젝트 초기 가설) | 같은 서비스의 정의다. 단 "확정값 아님" — GATE 1 에서 바뀌면 S1 하한도 따라 재검토 |
| PRD §60 · SRS BASE-002 | "최근 N일 미구매 → Win-back Coupon", N 은 TBD | 규칙의 모양만 준다 |
| `docs/data_spec.html` §12.1 · §13.1 | 안 A 의 전문과 S2~S5 의 타깃팅 기준, 모든 AI 전략 예산 ≤ C_rule | 이 저장소의 설계 문서. 그대로 따른다 |
| `config/economic_config.yaml` | T3 = 7,000원(50,000원 이상), 메시지 30원, 캠페인 고정비 100,000원 | 계획 비용 계산에 그대로 쓴다 |
| Radcliffe (2007) Qini · Künzel et al. (2019) X-learner | Qini 곡선 정의, X-learner 구성 | 지표·모델 구현의 근거. 우리 데이터에서의 성능 근거는 아니다 |

상한 90일 · 구매 2회 조건의 **외부 근거는 찾지 못했다** — data_spec 의 실무 관례 서술뿐이다.

## 결정

**S1 = 안 A.** `src/decision/strategies.py::S1_RULE` · `plan_S1`. 선택 입력
(`lifetime_order_count`·`eligible`)이 없으면 그 조건은 `not_run` 으로 표시한다(`s1_eligibility`).
`budget_krw=None` 이면 조건 충족 전원 — GATE 2 에서 C_rule 을 실측하는 실행이다.

**S2~S5** (모두 `budget_krw` 필수, 고객당 계획 비용 `costs[t]` 누적이 예산 이하):

| ID | 순서 | 처치 |
|---|---|---|
| S2 | `churn_p` 내림차순 | 전원 T3 (S1 과 같은 처치 — 차이가 타깃 선정에서만 나오게) |
| S3 | `churn_p × max_t CATE_t` 내림차순, CATE ≤ 0 제외 | CATE 최대 처치 (비용 무시) |
| S4 | `max_t (CATE_t × 가치 − cost_t)` 내림차순, 양수만 | 그 최대 처치 |
| S5 | 다중선택 배낭 탐욕 근사 (`optimize.optimize_budget`) | 최적화 결과 |

가치 = CLV × `margin_rate`(주어진 경우). `margin_rate` 가 없으면 CLV 를 이미 **이익 기준**으로 본다.
계획 비용 = 처치 단가 + 메시지 비용(쿠폰 전량 사용 가정의 **상한**) — 실현 비용이 예산을 넘지
않게 하는 보수적 선택이다.

**근거:** S1 은 위 조사의 설계 문서(data_spec §12.1)를 따르고, S2~S5 는 data_spec §13.1 의
"한 단계씩 정보를 더한다" 구조를 따른다. S3 은 이슈 지시(위험×CATE)를 따랐다.

**통합 계약(오케스트레이션 PR #154 에 맞춤):**

- `evaluate_uplift_models` 의 `best_method` 는 제안 모델 중 **Validation Qini**(train 안에서 다시 떼어 낸
  25%) 최고다. Test 지표로 고르지 않는다 — `src/decision/AGENTS.md` "Test 를 보며 반복 조정하지 않는다".
- 결과 y 결측 행은 **제외하고 건수**(`n_outcome_missing_excluded`)를 남긴다. Feature X 의 NaN 은 그대로
  HistGB 에 넣는다(결손을 0 으로 채우지 않는다).

## 기각한 안과 기각 사유

| 안 | 왜 택하지 않았나 |
|---|---|
| S1 안 B (30일) | 프로젝트 자체 At Risk 정의(28일)와 다른 숫자를 기준선에 쓰면 비교 근거가 둘이 된다 |
| S1 안 C (42일+) | 기준선을 약하게 만들어 Incremental Profit 을 부풀린다 — BASE-003 이 막으려는 것 |
| S5 를 LP(scipy `linprog`)로 정확히 풀기 | 정수성 완화 후 반올림 규칙이 필요하고 스프린트 3시간 안에 검증 불가. Greedy 도 OPT-003 이 허용 |
| best_method 를 Test Qini 로 고르기 | Test 를 보고 모델을 고르면 Test 가 더 이상 Test 가 아니다. Validation 으로 고르고 Test 는 보고만 한다 |
| 기여이익이 없을 때 매출 × 가중 마진율(0.26)로 COGS 추정 | `economic_config.yaml` 이 그 블록을 생성 파라미터로만 두고 비율 곱셈을 EC-1 위반으로 명시한다. 대체값은 과대평가임을 표시하고 그대로 둔다 |
| 세그먼트 임계를 절대값(예: uplift > 0.02) | 결과 변수 단위(구매 확률 vs 원)에 따라 의미가 바뀐다. 이슈 지시대로 분위수 기반 |

## 이 결정이 틀렸다면 어떻게 드러나나

- S1 대상자 수가 data_spec §12.2 추정(Eligible 의 약 20%)과 크게 다르면 28~90일 창이 이 서비스의
  구매주기와 맞지 않는 것이다. **이것을 보고 S1 을 바꾸면 안 된다** — GATE 1 에서 Churn 정의가
  바뀐 경우에만 FREEZE-003 절차로 재정의한다.
- S5 의 기대 순이익이 같은 예산의 S4 보다 낮으면 탐욕 근사가 나쁜 것이다(`test_budget_optimize`
  가 6명 문제에서 전수 탐색 최적의 70% 이상만 확인한다 — 최적 보장 없음).
- 세그먼트 '≈0 띠'가 |uplift| 의 60% 분위수라 비-중립(양·음) 고객이 최대 약 40% 로 제한된다.
  실제 효과가 넓게 퍼진 데이터에서는 Persuadables 를 과소 판정한다.

## 민감도

- S1 하한 28→22/34일(±20%): 대상자 수와 C_rule 이 바로 바뀌고 모든 AI 전략 예산 상한이 따라
  바뀐다. 이 값이 결과 전체에 가장 크게 작용한다.
- 계획 비용(상한 vs 기대값): 쿠폰 사용률이 30% 면 기대 비용은 상한의 약 1/3 이다. 상한을 쓰면
  같은 예산에서 AI 전략이 고르는 고객 수가 그만큼 적다 — AI 에 불리한 방향의 보수적 오차다.
- `uplift_band_q` 0.6 ±0.12: Persuadables·Sleeping Dog 비율이 대략 ±12%p 움직인다.

## 남은 불확실성

- GATE 2 정식 봉인(C_rule 실측·`config/gate1_lock.yaml` 류 기록)은 하지 않았다. AGENTS.md 가 말하는
  `strategies/rule_based.py` 경로가 아니라 `strategies.py` 에 두었다(이슈 지시 시그니처) — 봉인 시
  경로를 합의해야 한다.
- CLV 의 기준(매출/이익)이 D5 에서 정해지지 않았다. `margin_rate` 를 넘기지 않으면 이익 기준으로
  읽는다는 가정이 S4·S5 결과를 좌우한다.
- X-learner 성향점수를 표본 비율 상수로 둔 것은 무작위 배정 전제다(SIM-010 기본값). 공개
  관측 데이터에 쓰면 편향이 생긴다.
- 증분 마케팅 ROI(`roi`)와 PRD §64 AI ROI(`ai_roi`)를 둘 다 낸다. AI 투자비 범위가 TBD 라
  `ai_roi` 는 호출자가 투자비를 넘길 때만 계산된다.
