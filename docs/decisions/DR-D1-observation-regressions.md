# DR-D1-observation-regressions — 관측 근거의 gap 경계·다중 유형 회귀

| 항목 | 내용 |
|---|---|

## 무엇을 정하는가

주장 범위와 gap 범위를 분리한 반례, 여러 이벤트 유형을 쓰는 F10/F29의 관측 불완전성 전파를 기존 계산 시험에 추가한다. 입력은 명시적 합성 정책·공개 22컬럼·ObservationClaim, 출력은 기존 canonical/reasons/감사 정보의 실제 값이다. 제품 코드의 기존 #127·#128 수정은 바꾸지 않는다.

## 정하지 않으면 무엇이 막히나

incomplete 주장 자체가 null을 만드는 시험만으로는 gap의 교차 조건을 확인할 수 없다. 다중 유형 Feature가 관측된 유형만 검사해도 단일 유형 시험으로는 놓칠 수 있다.

## 선택지

| 안 | 장점 | 한계 |
|---|---|---|
| 넓은 unknown 주장과 독립 gap, 정상 complete와 비교 | O는 고정하고 I의 유무로 gap 판정을 분리 | 실제 evidence 제공 증명이 아님 |
| 주장 범위=gap인 기존 시험만 유지 | 단순 | gap 자체 분기를 분리하지 못함 |
| 제품 관측 정책을 함께 변경 | 정책을 바꿀 수 있음 | 승인된 결함 수정 보존 범위를 벗어남 |

## 조사한 것

설계 missing-policy의 복수 사유와 [start,end), 현재 Window.overlaps/observation_reasons 및 #127·#128 수정 기록을 대조했다. F10은 30일 A, F29/F30은 90일 A이며 A는 마케팅 노출3종을 제외한13종이다. Dictionary의 출처 파생 검증은 EventBatch 경계이며 SessionFact의 E/pin 대조와 다르다.

## 결정

구현 전 선택은 시험·설명 보강이다. unknown 주장 기간은 gap보다 넓게 고정한다. P1/P2/P3·KST/UTC에서 gap이 요청 시작에 끝남/끝에 시작함을 나누고 O와 I를 독립 기대한다. search의 부분 불완전은 검색이 실측되지 않아도 A를 사용하는 Feature에 전파한다. A 밖 마케팅 유형·다른 기간은 정상 대조군이다. Dictionary에는 EventBatch·세션 사실 커널의 검증 범위를 명시한다.

## 기각한 안과 기각 사유

incomplete/gap이 같은 범위인 사례만 반복하면 gap 분기를 독립 확인할 수 없어 기각했다. 세션 duration·운영 정책·관련 없는 정보성 지적을 함께 고치는 안도 범위 밖이어서 기각했다.

## 이 결정이 틀렸다면 어떻게 드러나나

gap이 배타적 끝에서 시작해도 I가 붙거나 P1의 포함 끝에서 시작하는데 I가 없으면 실패다. search 근거 결손에서 F10/F29가 정상값으로 남거나 마케팅 노출 근거만으로 F10이 null이면 실패다.

## 민감도

같은 부분 근거도 30일/90일 창에 따라 영향이 달라야 한다. 정책 선택은 합성 조건으로만 바꾸고 운영 기본값으로 확정하지 않는다.

## 남은 불확실성

실제 SD3 제공 계약과 SD1–SD8은 미결정이다. 기존 F6–F10·R1–R4 및 세션 의미 문제는 수정하지 않는다. 이 회귀 추가로 실제 입력 인수나 D1 전체 완료를 판정하지 않는다.
