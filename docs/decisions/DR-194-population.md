## 무엇을 정하는가

1. SIM-005(생성 이탈률 15~25%)와 처치 가드레일(ATE 3~6%p · 쿠폰 5~20% · Sleeping Dog 8~15% · Persuadable 11~21%), 실측 F12 · F14 를 **어느 모집단에서 판정하는가.**
2. 시스템 팀(#234)에 공유할 **정의** — RCT · S1 eligible · 결과 집계에 쓰인다.
3. 실험 규모(RCT T/C 각 1만+ · 본선 13개월+)가 고객 수 · 생성 시간 · 가드레일 표본에 주는 영향.

## 정하지 않으면 무엇이 막히나

- #196(D 경로 · 쿠폰 받기 배율 재조정)이 어느 값을 띠에 맞출지 모른다. 같은 실행에서 이탈률이 ① 16% · ② 42%, ATE 가 ① 2~4%p · ② 7.5~10.2%p 로 갈린다.
- GATE 1(스프린트 3, #208)의 판정 기준을 사전에 고정할 수 없다.
- #234 가 결정 계층에 적용할 정의가 없다.

## 선택지

① = 직전 42일 구매 고객(`guardrails.py` 가 쓰던 판정 모집단). ② = data_spec §4.1 eligible(가입 ≥ 60일 ∧ 구매 ≥ 1 ∧ 마지막 구매 ≥ 14일 전, 지금 RCT 배정 대상).

**근거:** 이탈률은 생성 기제의 성질이라 T0 와 무관한 분모(①)에서 재야 하고, 외부 참고치와 같은 꼴도 ① 이다(#193). 처치 지표는 처치가 실제로 일어나는 모집단(RCT 대상 ②)에서 재야 시스템 팀이 보는 실험과 같은 것을 맞춘다. 판정 결과(① 통과 · ② 실패)는 고르는 기준이 아니었다 — 그 증거로 이 결정은 ATE 를 띠 밖으로 보낸다.

### 실험 규모 영향 (시뮬 쪽, #164 로 공유)

| 항목 | 값 | 근거 |
|---|---|---|
| RCT T/C 각 1만+ 에 필요한 ② 고객 | 2만 명(1:1) | FR-05 |
| 필요한 생성 고객 수 | **약 4.3만 ~ 4.9만 명** (② 비율 41%(T0 = 180일차) → 4.9만, 45~47%(272일차) → 4.3~4.4만) | 위 모집단 크기 측정(sim-0.4). data_spec 의 2.6만(78% 가정)으로는 모자란다 |
| 생성 시간 | 고객 × 일수에 거의 비례 — 20,000명 × 600일 591초(sim-0.4), 609.7초(#243 sim-0.6). 5만 명 × 600일 ≈ **25분**, 5만 명 × 700일 ≈ **29분**(추정, 선형 외삽) | DR-167 실측 |
| 참 효과 계산 | 배정 고객당 약 3ms(DR-143) — 2만 명 배정 ≈ 1분 | |
| 가드레일 표본 | ② 의 ATE 표준오차 ≈ √((P + D) / n). seed 42 에서 P + D ≈ 14% → n = 1,661 이면 0.9%p. **±0.5%p 로 판정하려면 ② 약 5,200명 → 생성 고객 약 1.3만 명**(seed 마다 약 3분 추정, 4,000명 실측 51.5초) | 위 guardrails 측정 |

- 고객 수를 늘리는 것은 생성 config 를 바꾸지 않는다(실행 인자). 시뮬레이터 판도 그대로다.
- 판정은 seed 하나가 아니라 여러 seed(3~5개)로 한다 — #160 · #243 리뷰에서 seed 마다 ±2%p 흔들렸다.

## 이 결정이 틀렸다면 어떻게 드러나나

- 시스템 팀(#234)의 RCT 대상 수가 ② 비율로 예상한 값(생성 고객의 약 41~47%)과 크게 다르면 → 정의가 다르게 구현된 것이다(정의만 비교하고 코드는 서로 보지 않는다).
- #196 보정 뒤에도 ② 의 ATE 가 여러 seed 에서 띠 위에 머물면 → 처치 강도만으로는 안 되고, ② 의 구성(마지막 구매가 오래된 고객이 많다)이 ATE 를 키우는 것이다. 그때 ATE 띠의 모집단을 다시 연다.
- ① 이탈률이 판이 바뀌면서 T0 에 따라 흔들리기 시작하면 → "T0 와 무관" 근거가 깨진 것이다.

## 남은 불확실성

- **ATE 띠(3~6%p)의 모집단이 정해져 있지 않다.** 원래 출처(SRS · PRD)에 수치가 없고, 외부 근거는 활성 고객(Hillstrom 최근 12개월 구매)과 리텐션 표적군(통신사 Operator 1)이 섞여 있다(「조사한 것」). ② 에서 ATE 가 띠 위인 것이 처치가 강해서인지, 활성 고객 기준 띠를 ② 에 댄 탓인지 가르지 못한다. #196 은 처치 강도가 아니라 D 경로로 ATE 를 내렸다(P − D = ATE). GATE 1 판정 기준(#208)에서 띠의 모집단을 명시할지 리드가 정한다(#245 리뷰).

- **외부와 같은 분모로 재면 시뮬레이터 이탈이 외부보다 높다**(180일 활성 24~26% vs 10.7~13.1%, 그중 14일+ 39~41% vs 28.6~31.8%). 외부 표본 선발 탓인지 이탈 기제 탓인지 가르지 못했다 — #196 범위에서 함께 본다.
- **라벨 경계 불일치:** data_spec §5 ② 는 (T0, T0 + 42], 시뮬레이터 참 효과 · 가드레일 · cj_label 은 [T0, T0 + 42). 하루 차이라 수치 영향은 작지만, data_spec 은 `shared_read_only` 라 이 DR 에서 고치지 않는다 — 양 팀 합의로 하나로 적는다.
- `realism_check.py` F12 의 표본 편향(배정 전 T0 에서도 처치 고객을 뺀다)은 리드 소유 스크립트라 고치지 않았다. 리드 판단으로 이슈를 연다.
- 규모 · 시간 수치는 sim-0.4 와 4,000명 측정의 외삽이다. 실제 4~5만 명 실행은 하지 않았다.
