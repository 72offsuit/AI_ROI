## 무엇을 정하는가

가상 고객의 첫 번째 층인 **Persona** 를 어떻게 둘지 정한다(3층 구조, `docs/data_spec.html:205`). 정할 것은 네 가지다.

- **종 수.** 5종, 6종, 7~8종 중 무엇으로 할지 정한다. 이슈 #76 리뷰 질문 *"왜 6종인가? 5종이면 무엇이 안 되나?"* 에 답한다.
- **구성비.** `ratio_bp` 를 무엇으로 둘지, 그 값에 근거가 있는지 정한다.
- **배정 방식.** 고객 한 명에게 페르소나를 어떻게 붙일지 정한다. 고객별 가중 추첨, 정확 할당, 블록 할당 중에서 고른다. "고객을 추가해도 기존 고객은 그대로"라는 성질과 n=26,000 에서 생기는 표본 구성비 편차를 함께 본다.
- **가입 시점.** S2 에서 P6 신규가입자를 언제 가입시킬지 정한다.

민감도 질문도 함께 다룬다. **한 페르소나 비중이 ±20% 바뀌면 모집단 Trait 꼬리 질량이 얼마나 움직이나?**

Trait 분포 자체는 `DR-S2-hidden-trait-dist` 가 정한다. 추첨 연산, 저장, config 결속은 `DR-S2-trait-sampling` 이 정한다.

## 정하지 않으면 무엇이 막히나

- **S3(층화 배정).** `docs/data_spec.html:328-329` 는 층을 `persona (6) × recency_bucket (4)` = 24개로 정의한다. 종 수가 곧 층 수이고, 층마다 정확한 1:1 분할을 요구한다.
- **S4(행동)·S5(이탈)·S6(처치 반응).** 세 태스크가 모두 페르소나 조건부 Trait 을 읽는다. 생성 이탈률 15~25%(SIM-005)와 처치 가드레일(Sleeping Dog 8~15% 등, `docs/data_spec.html:372-376`)이 구성비에 직접 걸린다(아래 「민감도」).
- **S7(GATE 1).** `CUSTOMER PERSONA v1` 을 봉인한다(SRS FREEZE-001 `:1610`). 봉인 뒤에는 AI 결과를 이유로 **Persona Ratio** 를 바꿀 수 없다(FREEZE-002 `:1626-1630`). 바꿀 수 있는 마지막 시점이 GATE 1 이전이다.
- 명세에도 빈칸이 있다. SRS `:2373` 이 "[TBD] Persona Ratio" 이고, CFG-001(`:345-375`)은 `personas:` 의 6개 키만 있고 값이 `{}` 다.

## 결정

**N6 · R-A · W · D0.**

1. **6종**으로 둔다. 저장값은 CFG-001 키를 그대로 쓴 코드 문자열이고, 문서용 별칭으로 P1~P6 을 둔다.

   | 별칭 | 코드(상태에 저장) | ratio_bp | 26,000명 기대 인원 |
   |---|---|---:|---:|
   | P1 VIP 충성 | `vip_loyal` | 800 | 2,080 |
   | P2 일반 충성 | `loyal` | 2700 | 7,020 |
   | P3 가격민감 | `price_sensitive` | 2200 | 5,720 |
   | P4 탐색형 | `explorer` | 1800 | 4,680 |
   | P5 이탈진행 | `churn_progressing` | 1500 | 3,900 |
   | P6 신규가입 | `new_customer` | 1000 | 2,600 |

   코드 문자열을 저장하는 이유가 있다. `P1` 같은 두 글자는 격리 테스트의 지문 검색(`tests/test_isolation.py` 확장, U3)에서 우연히 일치하기 쉽다. 그리고 CFG-001 이 이미 이 키를 쓴다.
2. **구성비는 data_spec §3.2 초안이다. `config/simulator_config.yaml` 의 `personas[].ratio_bp` 에 정수 bp 로 둔다.**
   - 합이 10000 이 아니면 로더가 거부한다. 정수 bp 를 쓰면 이슈 완료 조건 "구성비 합 1.0"을 부동소수 반올림 없이 정확히 검사할 수 있다.
   - 배열 순서가 곧 추첨 순서다.
   - **이 값에는 외부 근거가 없다.** `docs/persona_spec.md` 와 config 주석에 그렇게 적는다.
3. **배정은 고객별 독립 가중 추첨이다.** `Stream(seed, customer_id, "persona", -1).weighted([ratio_bp…])` 로 뽑는다.
   - 열쇠에 `num_customers`·`profile` 이 없다. 그래서 15명 세계는 16명 세계의 앞 15명과 같다.
   - `day = -1` 은 행동 스트림(day ≥ 0)과 겹치지 않는다(`DR-S2-trait-sampling`).
4. **S2 에서는 전원 Day 0(`calendar_start`)에 가입한다.** P6 의 Day 1~272 가입 일정은 S3 가 이벤트 변경과 버전 상향을 함께 맡는다(사용자 확정 U1).

**근거.**

- **6종 — 리뷰 질문 "왜 6종인가? 5종이면 무엇이 안 되나?"에 대한 답.**
  - 첫째, 6종은 SIM-001 의 MUST 다. 5종은 요구사항 위반이다.
  - 둘째, 요구사항을 빼고 보아도 5종이면 무언가가 실제로 사라진다. `DR-S2-hidden-trait-dist` 의 결합 방식(페르소나 조건부 + 페르소나 안 독립)에서는 **Trait 사이의 상관과 꼬리가 전부 페르소나 혼합에서만 나온다.** 페르소나 하나를 빼면 그 성분이 만들던 꼬리나 상관이 없어지고, 남은 성분의 μ 를 바꾸지 않는 한 되살릴 수 없다.

  한 페르소나를 빼고 나머지를 비례 재조정해 계산했다(κ=12, 해석해).

  | 뺀 페르소나 | 가장 크게 사라지는 것 | 6종 → 5종 |
  |---|---|---|
  | P1 VIP | 고객단가 꼬리(PRD §20 High-value 세그먼트의 자연 공급원) | P(`base_order_value` > 10만 원) 3.94% → **2.26%** (P1 혼자 1.86%p 기여) |
  | P2 일반 충성 | 기준 질량 — 빠지면 모든 꼬리가 부푼다 | Persuadable 후보 질량 33.8% → 43.4%, P(`cart_abandonment` > 0.6) 17.3% → 23.5% |
  | P3 가격민감 | 쿠폰·가격 동반 민감 | Persuadable 후보 질량 33.8% → **15.8%**, corr(coupon, price) +0.65 → **+0.25** |
  | P4 탐색형 | 장바구니 이탈 꼬리 | P(`cart_abandonment` > 0.6) 17.3% → **6.6%** |
  | P5 이탈진행 | Sleeping Dog 후보, Day 0 감쇠 집단(`docs/data_spec.html:267-270`) | P(`marketing_fatigue` > 0.6) 6.18% → **0.70%** (P5 혼자 5.59%p 기여) |
  | P6 신규가입 | **Trait 꼬리가 아니라 시간.** 이력 길이가 다른 고객(S3 중도 가입, Eligible 제외), PRD §20 S6 New Customers·온보딩 전략 | S2 꼬리 질량 변화는 작다(±2%p 이내). P6 의 존재 이유는 S3 에서 드러난다 |

  "Persuadable 후보 질량"은 P(`coupon_sensitivity` > 0.6, `marketing_fatigue` ≤ 0.6) 이다(`DR-S2-hidden-trait-dist` 정의).
- **7~8종을 두지 않는 이유.** PRD §19 가 배송민감·프로모션피로를 Trait 상위 분위로 두기로 이미 정했다. 지금 구성에서도 그 꼬리가 충분히 생긴다. P(`shipping_fee_sensitivity` > 0.7) 은 15.6% 이고 P(`marketing_fatigue` > 0.6) 은 6.2% 다. 둘을 페르소나로 추가하면 같은 꼬리를 두 번 표현하게 된다. 그 비율에도 근거가 없기는 마찬가지다.
- **구성비 R-A.** 근거가 없다는 점에서는 R-B(균등)와 같다. 그런데 외부 자릿수 대조에서 R-A 가 더 낫다. 생성 모수만으로 계산한 모집단 평균을 오픈서베이 2023 의 컬리 이용자 평균과 비교했다.
  - **구매 빈도.** (방문/주 × 방문당 구매확률 × 30/7)로 근사하면 R-A 는 월 2.53회다. 설문은 2.5회다. 이 근사는 S4 의 `cycle_factor`·감쇠를 빼서 상한값이다.
  - **객단가.** `base_order_value` 의 모집단 평균은 45,889원이다. 설문은 44,800원이다.
  - 자릿수가 같다는 것은 "R-A 가 크게 틀리지 않았다"는 약한 신호일 뿐이다. 설문 평균 두 개로는 6개 비율을 식별할 수 없으므로 **보정에 쓰지 않는다**(R-C 기각).
  - R-B 로 바꾸면 P1(월 8.1회 근사, 객단가 중앙값 72,000원) 비중이 8% 에서 16.7% 로 두 배가 된다. 그러면 모집단 평균이 설문 자릿수에서 멀어진다.
- **배정 W.** 표본 구성비 편차는 표집 오차 수준이고, 구성비 자체의 불확실성보다 한 자릿수 작다.

  | 페르소나 | n=26,000 표준편차 | 99.9% 범위 | n=5,000 표준편차 |
  |---|---:|---:|---:|
  | P1 | 16.8 bp | ±55 bp | 38.4 bp |
  | P2 | 27.5 bp | ±91 bp | 62.8 bp |
  | P3 | 25.7 bp | ±85 bp | 58.6 bp |
  | P4 | 23.8 bp | ±78 bp | 54.3 bp |
  | P5 | 22.1 bp | ±73 bp | 50.5 bp |
  | P6 | 18.6 bp | ±61 bp | 42.4 bp |

  - 전체 총변동거리(TV)는 n=26,000 에서 평균 54 bp 이고 99.9분위가 120 bp 다(몬테카를로 2만 회).
  - 비교 대상인 구성비 자체의 불확실성은, P2 를 ±20% 로 보면 ±540 bp 다.
  - 몬테카를로 기준 표본(seed 42)의 실현 구성비는 802/2721/2164/1803/1516/994 bp 였다.
  - S3 는 층 안에서 정확한 1:1 로 나누므로(`docs/data_spec.html:328-329`) 이 편차는 처치·통제 균형에 영향을 주지 않는다.
  - 증거는 "구성비가 선언값과 일치"를 카이제곱(자유도 5, α=0.001)으로 검정해 남긴다. 고객별 독립이라 다항분포 가정이 정확히 성립하고, 그래서 이 검정이 의미가 있다.
- **비중 변경과 짝지은 비교.** 같은 고객의 추첨값이 그대로이므로, 비중을 바꾸면 누적 경계를 넘는 고객만 페르소나가 바뀐다. P5 를 ×1.2 로 바꾸면 26,000명 중 **1,685명(6.5%)** 만 바뀌었다(몬테카를로). 짝지은 민감도 분석에서 차이가 비중 변경에서만 온다.

## 기각한 안과 기각 사유

| 안 | 왜 택하지 않았나 |
|---|---|
| N5 (5종) | SIM-001 MUST 위반이다. 그리고 빠지는 페르소나가 맡던 꼬리나 상관이 사라진다(위 표). P3 를 빼면 Persuadable 후보가 절반 아래로 줄고, P5 를 빼면 Sleeping Dog 후보가 0.7% 로 떨어진다 |
| N7~8 | PRD §19 가 명시적으로 기각했다. 같은 꼬리를 두 번 표현하게 되고, 층이 28~32개로 늘어난다. 추가 비율에도 근거가 없다 |
| R-B (균등) | "모른다"는 R-A 와 같은데, PRD §17 서술(VIP 는 소수, 일반 충성이 다수)과 외부 자릿수 대조 모두에서 R-A 보다 멀다 |
| R-C (외부 모멘트 역산) | 국내 자료는 자기응답 이용자 평균 두 개뿐이고 6개 비율을 식별할 수 없다. S4 행동식이 생기기 전에 역산한 값은 S4 에서 다시 틀어진다. 실현값을 보고 GATE 1 전에 조정할 여지는 S4·S5 의 가드레일 절차에 남긴다 |
| E (정확 할당) | 배정이 `num_customers` 에 의존한다. "15명 = 16명의 앞 15명" 성질과 Small/Main 간 같은 고객 동일성을 잃는다. 얻는 것은 인원이 정확히 맞는 것뿐인데, 편차(±91 bp)가 구성비 불확실성(±540 bp)보다 훨씬 작아 실익이 없다 |
| B (블록 할당) | 고객 추가 불변성은 지킬 수 있다. 하지만 bp 해상도를 지키려면 블록이 10,000명이어야 하고, 같은 블록 고객끼리 독립이 아니라 카이제곱 검정이 늘 과소분산이 된다. 순열 코드가 늘어난다. 얻는 정밀도에 실익이 없는 것은 E 와 같다 |
| D-P6 (지금 P6 중도 가입) | 사용자 확정 U1 에 따라 S3 로 넘긴다. 지금 하면 이벤트가 바뀌어, 행동이 그대로임을 증명하는 U4 대조(라벨만 바꾸면 sim-0.1 골든과 같다)를 할 수 없다 |
| 페르소나 ID(`P1`)를 상태에 저장 | 두 글자 문자열은 격리 지문 검색에서 거짓 양성을 낸다. CFG-001 이 이미 코드 키를 쓴다 |

## 이 결정이 틀렸다면 어떻게 드러나나

- **구현 결함.** 실현 구성비가 카이제곱(자유도 5, α=0.001)에서 기각되면 배정 구현이 틀렸다. 고객 15명과 16명의 앞 15명 페르소나가 다르면 배정이 `num_customers`·`profile` 에 의존하고 있다.
- **S5 이탈률 가드레일 15~25%.** S4 행동식 아래에서 생성 이탈률이 이 범위에 못 들어가고, 원인이 P5 비중(1500 bp)에 있다고 드러날 수 있다. 그러면 GATE 1 전에 구성비를 다시 연다. 조정 근거는 가드레일뿐이고, AI 결과를 근거로 삼지 않는다(FREEZE-002).
- **S6 Sleeping Dog 가드레일 8~15%.**
  - data_spec 처치식(`docs/data_spec.html:351-352`)에서 τ 가 음수가 되려면 `marketing_fatigue > 0.6` 이어야 한다. 그래서 경로 의존 효과를 빼면 Sleeping Dog 비율의 상한은 P(`marketing_fatigue` > 0.6) 이다.
  - 이 값이 **지금 6.18% 로 가드레일 하한 8% 보다 낮다.** P5 비중을 ±20% 바꿔도 5.1~7.3% 에 머문다.
  - S6 가 8% 에 닿지 못하면 이 DR(P5 비중)과 `DR-S2-hidden-trait-dist`(P5 의 fatigue μ)를 GATE 1 전에 다시 연다. 지금 고치지 않는 이유는 `DR-S2-hidden-trait-dist` 「이 결정이 틀렸다면」에 적었다.
- **외부 자료.** 국내 온라인 식료품의 행동 세그먼트 비중 자료가 나와 R-A 와 크게 다르면 구성비를 다시 연다.
- **5종으로 충분하다는 증거.** S4 이후 어떤 페르소나를 다른 페르소나에 합쳐도 실현 KPI 분포가 구분되지 않는다면 그 페르소나는 중복이다. 요구사항은 6종을 유지하라고 하므로 페르소나는 유지하고, 그 사실만 기록한다.

## 민감도

**한 페르소나 비중을 ×0.8 / ×1.2 로 바꾸고 나머지를 비례 재조정했을 때의 꼬리 질량.** 기준값과 몬테카를로 교차 확인은 `out_mix_tails.txt` 4절, 6절에 있다. 해석해와 짝지은 n=26,000 몬테카를로의 차이는 0.2%p 이내였다.

| 바꾼 비중 | P(fatigue > 0.6) | Persuadable 후보 질량 | P(ship > 0.7) | P(cart > 0.6) | P(churn_prop > 0.5) | P(AOV > 10만) |
|---|---|---|---|---|---|---|
| 기준 | 6.18% | 33.81% | 15.62% | 17.28% | 11.73% | 3.94% |
| P1 ×0.8 / ×1.2 | 6.26 / 6.10 | 34.39 / 33.23 | +0.27 / −0.27%p | +0.30 / −0.30%p | +0.20 / −0.20%p | **−0.34 / +0.34%p** |
| P2 ×0.8 / ×1.2 | 6.60 / 5.77 | 35.72 / 31.90 | +1.04 / −1.04%p | +1.23 / −1.23%p | +0.86 / −0.86%p | −0.09 / +0.09%p |
| P3 ×0.8 / ×1.2 | 6.53 / 5.84 | **30.20 / 37.42** | **−2.13 / +2.13%p** | +0.14 / −0.14%p | +0.56 / −0.56%p | +0.18 / −0.18%p |
| P4 ×0.8 / ×1.2 | 6.38 / 5.98 | 34.66 / 32.96 | +0.34 / −0.34%p | **−2.13 / +2.13%p** | +0.28 / −0.28%p | +0.09 / −0.09%p |
| P5 ×0.8 / ×1.2 | **5.09 / 7.28** | 34.46 / 33.16 | +0.42 / −0.42%p | +0.33 / −0.33%p | **−1.85 / +1.85%p** | +0.12 / −0.12%p |
| P6 ×0.8 / ×1.2 | 6.32 / 6.05 | 33.42 / 34.20 | +0.02 / −0.02%p | +0.21 / −0.21%p | +0.10 / −0.10%p | +0.06 / −0.06%p |

읽는 법은 셋이다.

- **각 꼬리는 사실상 한 페르소나가 쥐고 있다.** fatigue 꼬리는 P5, 쿠폰·배송 꼬리는 P3, 장바구니 꼬리는 P4, 고객단가 꼬리는 P1 이 쥐고 있다. 그 페르소나 비중을 ±20% 바꾸면 해당 꼬리가 상대적으로 약 ±10~18% 움직인다.
- **같은 ±20% 라도 비중보다 Trait μ 쪽이 훨씬 크게 움직인다.** 전 페르소나 fatigue μ 를 ±20% 바꾸면 P(fatigue > 0.6) 이 2.16~11.92% 사이를 움직인다(`DR-S2-hidden-trait-dist`).
- **구성비의 근거 부족은 꼬리 질량을 수 %p 범위에서 흔든다.** Trait μ 의 근거 부족은 그것을 배 단위로 흔든다. 그래서 조사와 대조 장치는 μ 쪽에 더 많이 투자해야 한다.

## 남은 불확실성

- **구성비의 외부 근거가 없다.** 국내 온라인 식료품의 행동 세그먼트 비중이 공개되면 해소된다. 현실적으로 그럴 가능성은 낮다. 그때까지는 위 민감도 표가 근거를 대신한다.
- **P6 10% 와 Eligible 약 78%.** data_spec §3.1(`:217`)은 26,000명을 "Eligible 약 78%" 가정으로 역산했다. 이 비율은 P6 중도 가입(S3)과 S4 행동식이 생겨야 정해진다. S2 의 전원 Day 0 상태에서는 확인할 수 없다.
- **Sleeping Dog 가드레일 하한 미달 신호(6.18% 이하 vs 8%).** S6 이전에는 실현값을 계산할 수 없다. Eligible 모집단에서는 P5 비중이 모집단보다 높아질 가능성이 있다. 최근 구매 14일 이상이라는 조건 때문이다. 하지만 Sleeping Dog 가 되려면 처치가 없을 때 유지돼야 하므로(Y(0)=1) 감쇠 중인 P5 는 오히려 Lost Cause 쪽으로 갈 수 있다. 방향을 단정할 수 없다.
- **이 DR 의 계산은 모두 생성 모수 수준이다.** S4 의 행동식(`cycle_factor`·감쇠·계절성)이 들어간 실현 KPI 는 다르다. 실현 구매 빈도·객단가를 외부 자릿수(월 2.5회, 44,800원)와 다시 대조하는 일은 S4 가 맡는다.
- 후속 이슈 후보(보고만 하고 고치지 않는다): SRS `:2373` "[TBD] Persona Ratio" 를 이 DR 에 연결할지와 그 시점은 리드가 정한다.
