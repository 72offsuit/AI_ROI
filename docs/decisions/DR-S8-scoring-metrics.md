## 결정

### 지표 (M)

| # | 결정 |
|---|---|
| M1 **PEHE** | **제곱평균제곱근**(√mean((τ̂ − τ)²)) 하나만 낸다. 절대값(MAE)은 내지 않는다 — 둘 다 내면 결과를 보고 유리한 쪽을 고를 수 있다. 참 τ 는 실현값이라 완벽한 기대 효과 추정기도 PEHE 가 0 이 아니다(바닥 ≈ √mean Var(τ∣x)). 그래서 **기준선 PEHE₀ = "모든 고객에게 같은 τ̂ = 그 모집단의 참 ATE" 를 준 PEHE** 와 비 **PEHE / PEHE₀** 를 함께 싣는다(1 미만 = 상수 ATE 보다 낫다). 편향 **mean(τ̂) − mean(τ)** 도 함께 싣는다(PEHE² = 편향² + 분산 분해) |
| M2 **PEHE · corr · 4분면 모집단** | 채점 대상 파일의 **채점 고객 전원**, 팔마다 따로(T1~T4). 배정 팔과 무관하다 — 모든 고객이 모든 팔의 잠재결과를 가지므로 배정으로 거를 이유가 없고, 거르면 전략 분기에서 타게팅 편향이 들어간다. 팔을 합친 평균은 내지 않는다 |
| M3 **Qini · Qini_oracle · 달성률** | DR-142 안 A 그대로(같은 관측 (W, Y) 위에서 정렬 기준만 τ̂ · τ, 동률 묶음, 1인당, Random = 0, oracle ≤ 0 이면 `None` + 사유). 모집단은 **무작위 배정(RCT) 분기 파일**의 `assigned ∈ {팔, T0}` 고객만. 전략 분기 파일에는 **Qini 를 내지 않는다**(배정이 무작위가 아니라 관측 Qini 가 편향된다) |
| M4 **corr(τ̂, τ)** | **Pearson 이 판정값**, Spearman 은 참고. 참 τ 가 −1 · 0 · 1 뿐이라 Spearman 은 동률이 대부분이다. 분산 0 이면 `None` + 사유 |
| M5 **4분면 혼동행렬** | 참 = (Y(팔), Y(T0)). 예측 = τ̂ > eps → Persuadable, τ̂ < −eps → Sleeping Dog, 그 밖 중립. **eps = 0 고정**, 다른 eps 는 리포트에 싣지 않는다. 핵심 비율은 `persuadable_as_sleeping_dog` · `sleeping_dog_as_persuadable`, 행렬은 건수로 |
| M6 **Sleeping Dog 타게팅 비율**(§14.1 Guardrail) | 참 4분면이 필요해 **S8 만 계산할 수 있다.** 전략 분기마다: 처치받은 고객(`assigned ≠ T0`) 중 그 팔의 참 Sleeping Dog 비율. 비교 기준 = 같은 파일 전원에서 그 전략의 팔 구성대로 무작위로 골랐을 때의 기대 비율. 단측 정확 이항검정, α = 0.05. **리드 결정(2026-11-09):** S8 **사후 진단으로만** 낸다 — 판정에 쓰지 않고 공개는 V1 시점 그대로다. §14.1 의 판정 전 Guardrail 은 시스템이 정답지 없이 계산하는 추정값으로 바꾼다(정의 · §14.1 수정은 양 팀 합의, 「남은 불확실성」 결정 4) |

### 제외 규칙 (X)

| # | 결정 |
|---|---|
| X1 **창 안 재배정 행** | 채점에서 **뺀다**, 뺀 수(`superseded_rows`)는 파일마다 싣는다. 그 행의 참 효과는 "더 배정하지 않았을 때" 의 값이라 관측과 어긋난다(#167). 지금 오케스트레이션(`advance(42)` 뒤 재배정)에서는 0 이어야 하므로 **0 이 아니면 경고**를 낸다 |
| X2 **파일 τ 불일치** | `tau_file_mismatch > 0` 인 파일은 **채점하지 않고** `invalid` + 사유. 잠재결과와 τ 가 어긋나면 참값 자체가 의심스럽다 |
| X3 **τ̂ 누락** | 누락 고객을 0 으로 채우지 않는다. 누락 수를 싣고 있는 고객만 채점하며, 누락이 그 팔 모집단의 1% 를 넘으면 그 팔은 `partial` |
| X4 **채점 파일 범위** | **Final Holdout(GATE 4) T0 의 파일만** 채점한다(§14 Primary 모집단 = Test 20%, 최종 1회). 개발 · 검증용 T0 파일은 채점하지 않는다 — 돌리면 그 자체가 중간 공개다 |

## 기각한 안과 기각 사유

| 안 | 왜 택하지 않았나 |
|---|---|
| PEHE 를 MAE 로 · 둘 다 | 표준(Hill)은 RMSE. 둘 다 내면 고르기가 된다 |
| PEHE 를 기대 τ 로(고객마다 여러 번 반복 시뮬) | 바닥은 없어지지만 고객당 반복 수 × 약 3ms 가 든다(#167 실측 5,000명 15초). 상대 PEHE(PEHE₀ 대비)로 같은 질문 — "상수 ATE 보다 나은가" — 에 답할 수 있다 |
| PEHE · corr 을 진짜 4분면별 부분집합으로 판정 | 이진 τ 에서 4분면 안의 τ 는 상수라 PEHE 가 편향만 잰다. 4분면 정보는 M5 혼동행렬이 맡는다 |
| 전략 분기에서도 Qini | 비무작위 배정이라 관측 Qini 가 편향된다(§14 "무작위 T/C 데이터로 산출") |
| eps 를 여러 개 싣기 | 결과를 보고 고르는 길이 된다. DR-142 「민감도」 의 0.02 는 참고로만 두고 리포트에는 싣지 않는다 |
| GATE 2 뒤 바로 실행 | Final Holdout 전에 숫자가 나오면 AI 개선(GATE 3) 단계에서 쓰일 수 있다 |

## 이 결정이 틀렸다면 어떻게 드러나나

- PEHE₀ 자체가 ATE 에 거의 무관하게 ≈ √(Persuadable + Sleeping Dog 비율)(지금 띠 기준 약 0.5)라 비가 1 근처에 몰리면 M1 의 판별력이 약한 것이다 — 그때도 기대 τ 반복으로 바꾸지 않고 corr 을 주 해석으로 쓴다.
- Final Holdout 에서 oracle ≤ 0 이 나오면 DR-142 대로 Στ 이득 곡선을 **별도 지표로** 병기한다(달성률 분모로 쓰지 않는다).
- X1 의 경고가 뜨면 오케스트레이션이 창 안 재배정을 하고 있다는 뜻이다 — 채점 전에 리드에게 올린다.

- 분기 목록과 참 효과 파일의 연결 키(결정 2) — **배정 시각 + 배정 내용 digest** 로 정했다(2026-11-12 · #224, 성환 확인 · 민정 동의). run_id · 배정 파일 이름 · 배정 시각만으로는 분기를 이을 수 없다.
  - 키 계산 함수는 시뮬레이터 공개 API 에 넣는다(성환, GATE 1 실측 뒤 별도 이슈 · PR). Final Holdout(#226) 실행 전에 들어와야 한다. 시스템 팀은 이 함수 값을 분기 목록에 넣기만 하고, digest 규칙을 따로 구현하지 않으며 시뮬레이터 코드와 참 효과 파일 이름을 보지 않는다. 함수 입력 형식과 배정 시각 표기 일치는 그 PR 의 시험으로 고정한다.
